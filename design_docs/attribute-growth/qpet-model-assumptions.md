# Q宠大乐斗早期版本镜像战回合数估算：模型假设与不确定性

> 本文件配合 `sim_qpet_turns.py` 与 `qpet-daledou-battle-turns.csv` 使用。  
> 所有假设均基于本地资料：`design_docs/qpet-daledou/battle-mechanics.md`、`research-notes.md`、`weapons-skills.md`。

## 1. 资料已确认的战斗规则

## 2. 本模型的核心公式

### 2.1 回合定义

资料中仅说明“速度决定每回合出手次数”，未给出回合与速度分配的精确换算。  
本模型采用最保守、最可复现的定义：

> **1 回合 = 双方完成一次完整攻击交换。**  
> 由于模拟的是**完全相同**的宠物，速度比为 1:1，因此每回合双方各获得 **1 次基础出手机会**；额外连击、反击不增加回合计数，而是视为同一次基础出手触发的追加攻击。

若速度不同，本定义可自然扩展为：按速度比分配每回合的基础攻击次数（例如 20 速度 vs 10 速度 ≈ 2:1）。

### 2.2 单次攻击伤害

```text
基础伤害 base = uniform(武器最小伤害, 武器最大伤害)      # 空手亦有基础伤害范围
原始伤害 raw  = base × (力量 / 10) × (1 + 技能加成) × 暴击倍率
最终伤害 dmg  = max(1, round(raw - 防御减伤))
```

- **力量系数 = 力量 / 10**：来自玩家社区推测（`research-notes.md` §9 明确标注“未证实”）。
- **技能加成**：空手场景使用“肉搏好手/武术好手 +20%”；武器场景使用“武器好手 +20%”。
- **暴击倍率 = 1.5**；武器场景暴击率 10%，空手场景暴击率 5%。
- **防御减伤**：以固定数值从最终伤害中减去，体现“减法防御”对 TTK 的拉长。

### 2.3 解析期望 TTK（`ttk_analytic` 列）

```text
E_raw   = 平均base × (力量/10) × (1+技能加成) × (1 + 暴击率×0.5)
E_dmg   = max(1, E_raw - 防御减伤)
DPR     = E_dmg × (1 - 闪避率)
ttk     = HP / DPR
```

该解析值**忽略**连击、反击、装死、控制与速度差异，仅作为与蒙特卡洛模拟结果对照的简化基准。

## 4. 模型明确未包含或简化的内容

以下内容在资料中存在，但为保持模型聚焦“镜像相同宠物的基础 TTK”，未纳入模拟：

- **控制/跳过回合**：企鹅吼、胶水、充气锤子、折凳等；在镜像战中双方概率相同，对期望 TTK 影响复杂，暂不模拟。
- **持续伤害**：企鹅挠痒、青龙戟毒等。
- **恢复技能**：矿泉水、真·圣水、师傅驾到；加入恢复会显著延长并引入平局风险。
- **特殊/R技/帮派/夫妻技能**：如来神掌、黑龙波、情比金坚、天马流星拳等；这些多为中后期或社交系统附带。
- **魂珠/入魂/升星**：资料列为 2011 年前后的强化体系，会改变暴击、命中等参数。
- **速度差异**：镜像战速度相同，因此速度比仅影响 1:1 出手；不同速度场景需额外扩展。
- **武器多样性**：仅选取“红缨枪”作为典型中型武器，未覆盖小型高连击、大型高伤等全部类型。

## 5. 结论使用边界

- 本 CSV 中的回合数是**在大量强假设下**的相对估算，用于观察“等级提升、武器获取、减法防御”对 TTK 的影响趋势，**不应被视为官方 Q宠大乐斗 的实际战斗回合数**。
- 由于力量系数、HP、防御减伤等关键参数均为社区推测或建模假设，不同取值会使绝对回合数产生显著变化；本结果应作为设计参考的“数量级”而非精确值。
