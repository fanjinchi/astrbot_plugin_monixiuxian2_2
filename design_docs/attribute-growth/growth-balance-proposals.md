# 属性成长与属性加成平衡设计方案

> 2026-07-30。基于 `attribute-growth-analysis.md` 的镜像战实测数据与
> `auto-battle-balance-web-research.md` 的业界调研，为"玩家侧"属性成长与加成体系
> 提出可选方案。**范围**：玩家成长、心法/功法/武器的数值框架；**不含**敌人/Boss
> 数值（待玩家侧定稿后再以其为锚设计 PvE）。

---

## 1. 设计目标

| # | 目标 | 量化标准 |
|---|---|---|
| G1 | 同级镜像战 TTK 健康 | 裸拳 8~15 回合；持同级典型武器 5~10 回合；任何等级不出现 1 回合秒杀 |
| G2 | 成长曲线跨等级稳定 | L1→L99 的镜像 TTK 波动 ≤ ±30%（锚：config 基准曲线全程 ≈9 回合） |
| G3 | 保留 destiny 随机乐趣 | 同等级玩家存在 build 差异（±5%~10% 属性方差 + 随机掉落），但方差不摧毁 G1/G2 |
| G4 | 为心法/功法/武器扩容预留数值空间 | 内容设计有明确"数值预算"约束，新增内容不需要重做平衡 |
| G5 | 可回归验证 | 任何改动可用 `sim_xiuxian_turns.py` 扩展版直接回归 |

现状问题（实测，详见 `attribute-growth-analysis.md` §3）：随机成长曲线与基准曲线脱节
（L99 玩家期望 HP 222 vs 基准 1570）、武器只放大伤害导致同级同装 1 回合秒杀、
减法护甲在高伤害区间失效。

## 2. 属性成长方案（三选一骨架 + 两个可叠加层）

### 方案 A：锚定基准 + 加权随机分配（Q宠式点数随机 + My Brute式 HP 独立通道）

每次突破成功：

- **气血（独立通道，My Brute 式）**：`+15`（可带 ±3 随机调味，期望不变）。
  HP 不再参与属性点随机分配——这是修复"HP 只拿到 1/4 随机点导致 TTK 崩塌"的关键。
- **战斗属性点 5 点（Q宠式逐点随机）**：每点独立掷骰 →
  **伤害 60% / 身法 25% / 迅捷 15%**（权重可调）。

期望与方差（98 次突破后）：

| 属性 | 期望 L99 | 基准 L99 | 标准差 | 说明 |
|---|---|---|---|---|
| 伤害 | 304 | 304 | ±11（±3.5%） | 与锚点一致，TTK 不被方差破坏 |
| 身法 | 128 | 103 | ±10 | 略高于基准，增加 build 差异 |
| 迅捷 | 79 | 54 | ±8 | 同上 |
| 气血 | 1570 | 1570 | ±47（若 ±3 随机） | 与锚点一致 |

镜像战期望 TTK：全程 ≈9~10 回合（与基准曲线一致，G1/G2 达标）。
build 差异来源：伤害型 vs 身法型的天然分化（高身法对高伤害形成闪避克制）。

### 方案 B：纯 destiny 轮盘（纯 My Brute 式）

每次突破只掷一次轮盘：`属性包 / 武器 / 功法 / 心法 / 潜心` 五选一。
属性包为主题打包（猛攻包 伤害+4、灵动包 身法+2迅捷+2、气血包 HP+50……），
包概率按期望=基准斜率标定；潜心=本次无掉落、下回必掉并+属性补偿。

- 优点：最贴近 My Brute/Q宠灵魂，每次突破都是事件；
- 缺点：方差大（可能连续不掉属性包），需要保底机制；标定与回归成本高；
  HP 通道仍需单独处理（气血包掉率必须保证期望 +15/级）。

### 方案 C：大境界百分比跃迁（AFK/一念逍遥式成长感包装）

小境界线性成长（同 A），突破**大境界**（练气→筑基→金丹……共 9 个）时全属性
额外乘 `(1 + r)`，r 保守取 8%~12%。

- 对镜像 TTK 无影响（双方同乘），跨大境界战力差拉大（碾压感、成长感）；
- 代价：跨境界 PvP 基本不可打，匹配必须按大境界分池；r 若失控则数值膨胀。

### 推荐组合（已决策，2026-07-30）

> **A 为骨架（已定）**：属性点 60/25/15 加权**纯随机**（不做三选一交互），
> 气血 +15 独立通道。
> **B 的轮盘降级为"机缘掉落层"叠加在 A 之上（已定方向）**：突破时属性点照发（A），
> 额外掷一次掉落轮盘：武器 / 功法 / 心法 / 丹药 / 潜心（潜心=本次不掉但下次必掉，
> 并给予补偿）。保底的具体形式见 §6 问题 5（待决策）。
> **C 不采用（已定）**：不引入大境界百分比跃迁。大境界的跨越感改由**内容境界门槛**
> 产生——武器/心法/功法的 `required_level_index` 在每个大境界解锁新一档内容
> （My Brute/Q宠 的内容驱动成长模式）。属性曲线全程线性可预测；跨大境界战力差
> 由装备/功法档位拉开，论剑/切磋只需软分池；"突破大境界后换新一档装备"本身成为
> 养成循环的驱动点。

## 3. 属性加成结构（心法/装备/丹药如何叠加）

### 3.1 三层加成模型（全系统统一公式）

```
最终属性 = (基础 + 成长 + Σ固定加成) × (1 + Σ百分比加成)
```

- **固定加成**：丹药、装备词条、传承。按品级定数值档位。
- **百分比加成**：心法、功法被动、宗门 buff。**相互之间加法叠加后再乘**
  （AFK 式），禁止百分比之间连乘（防膨胀失控）。
- **Q宠式缩放被动**（推荐用于"属性心法"）：加成 = `基础属性 ÷ n + c`，
  随玩家成长自动升值、永不淘汰。例：`大力诀：伤害 +基础伤害÷2+3`。
- My Brute 式一次性大百分比（如 `神力诀：伤害 +50%`）应稀少且高品级，
  且与其他百分比加法叠加。

### 3.2 战斗概率 caps（硬上限，写进结算层而非靠内容自觉）

| 概率/效果 | 上限 | 现状 |
|---|---|---|
| 闪避率 | 40% | 现 50% → 建议降到 40%，为身法心法留空间 |
| 格挡率 | 30%（现状不变） | ✓ |
| 暴击率 | 50% | 现固定 15%，开放加成后设 cap 50% |
| 暴击伤害 | ≤ 200% | 现 150% |
| 单次行动连击 | ≤ 2 次追加 | 新增，配合轻型武器 |
| 控制（跳过回合） | 单场 ≤ 1 次/人，同一目标递减 | 新增功法时约束 |
| 受伤减免（百分比区合计） | 40% | 配合 3.3 护甲改动 |

### 3.3 护甲公式：减法 → 百分比（def/(def+K)）（已决策采用）

现状 `max(1, 伤害−护甲)` 在武器数百上千伤害时形同虚设（实测）。改为：

```
减伤率 = 护甲 ÷ (护甲 + K)，K = 100 + 10 × 等级   （Idle Heroes 式随等级缩放）
最终伤害 = max(1, floor(伤害 × (1 − 减伤率)))
```

效果：护甲全等级有效（不刮痧、不免伤），同级典型护甲减伤约 10%~25%；
心法/功法的百分比减伤（皮糙肉厚类）与此**乘法叠加**并受 3.2 的 40% 总上限约束。
格挡机制（5%+护甲×0.001，上限 30%，格挡减半）保留不变。

> 决策备注（2026-07-30）：接受此次破坏性变更；现有护甲/装备词条数值的重做
> 纳入 §5 第 5 步"内容扩容"阶段统一设计。

## 4. 心法/功法/武器的数值预算约束（内容设计规范）

扩容内容时每条内容按预算设计，不需要重做平衡。

### 4.1 武器（三角定位，My Brute/Q宠式）

| 定位 | 数值特征 | 每击期望预算 |
|---|---|---|
| 轻型（匕/刺） | 低 base、+迅捷/身法词条、连击率 | 同级 HP 的 1/10 ~ 1/8 |
| 中型（剑/枪） | 均衡、格挡/反击词条 | 同级 HP 的 1/8 ~ 1/6 |
| 重型（锤/斧） | 高 base、−迅捷、破甲词条 | 同级 HP 的 1/6 ~ 1/4（低频高伤） |

- **武器面板按品级固定、不随等级浮动**（Q宠式"卡牌化"），`required_level_index` 控制可用境界；
- 验算示例（L10，HP 235）：灵品剑 base=12、K=0.6、+5 伤害 →
  每击 ≈ 12+(37+5)×0.6 ≈ 37 ≈ HP/6.3 → 镜像 TTK ≈ 6 回合 ✓ 落在 G1 的 5~10 区间；
- 反例（现状）：鸿蒙断魂匕每击数千 vs L99 HP 1570 → 1 回合秒杀，必须按预算重做数值；
- 防具同步提供 HP/护甲，保证"同级同装"镜像 TTK ≥ 5 回合。

### 4.2 功法（触发式，期望预算制）

现有结构（trigger_rate × effect_value）直接适用，加预算约束：

- **期望输出增益 ≤ +30%/槽位**（`trigger_rate × (effect_value−1) ≤ 0.3`，
  例：25% × 1.5 倍 = 期望 +37.5% 略超，应降到 20% 或 1.4 倍）；
- 奥义/绝招（once_per_battle）：预算 ≤ 同级 HP 的 50%，必中类再减半；
- 控制/恢复类：控制受 3.2 caps 约束；恢复按"单场 ≤ 最大 HP 30%"预算；
- 路线倍率（灵修/体修）作为横向 build 差异，±20% 以内。

### 4.3 心法（被动基座 + 功法池）

- 现有 `passive_bonus`（如 hp_percent +10%）走 3.1 百分比区，单心法预算 ≤ 15%；
- 属性心法优先用 Q宠式缩放被动（`÷n+c`），避免"低阶心法后期淘汰"；
- 心法决定功法池（现状已如此）→ 心法是 build 的"职业"，数值差异克制、
  池子差异为主，符合 My Brute/Q宠"内容差异 > 数值差异"的原则。

### 4.4 获取节奏（机缘轮盘）

突破掉落轮盘建议权重（可随大境界上调高品掉率）：
武器 25% / 功法 25% / 心法 15% / 丹药 20% / 潜心 15%（下次必掉 +2 自由点）。
重复武器/功法 → 转化为升星/领悟材料（参考 Q宠黄金卷轴升星，成功率递减、
4→5 有降级风险——高风险强化是后期数值消耗口，预算单列）。

## 5. 落地路线（建议顺序）

1. **成长模型迁移**：实装方案 A（+可选 C），写一次性玩家属性重标定迁移
   （参照此前五维→四维迁移脚本的模式），把存量玩家映射到新曲线最近点；
2. **护甲公式切换**：减法 → def/(def+K)，K=100+10×level，同步调整护甲词条数值；
3. **战斗 caps 实装**：闪避 40%/暴击 50%/连击上限/受伤减免 40% 写进 CombatEngine；
4. **机缘轮盘**：突破流程加掉落层（B 层），潜心保底；
5. **内容扩容**：按 §4 预算表批量设计武器/功法/心法（每品级一个"标杆件"先定档）；
6. **回归验证**：扩展 `sim_xiuxian_turns.py` 覆盖新成长 + 标杆装备镜像战，
   验收 G1（裸拳 8~15 / 持械 5~10 / 无秒杀）与 G2（跨等级波动 ≤±30%）；
7. **之后**再以此曲线为锚设计敌人/Boss（PvE）与论剑匹配分池。

### 问题 5 详解：突破掉落轮盘的保底机制

轮盘是属性点之外的额外掉落层（武器 25% / 功法 25% / 心法 15% / 丹药 20% / 潜心 15%），
每次独立随机，存在干旱期：珍贵物品（武器+功法+心法，合计 65%）连续不掉的概率
为 3 连空 ≈4.3%、5 连空 ≈0.5%。三种保底形式：

**形式一：潜心（Q宠式，结果内置补偿）**
轮盘内置"潜心"结果（15%）：本次不掉落，补偿 +5 气血，且**下次突破必掉珍贵池**。
叙事感强（闭关潜心、暂无机缘、修为精进）；但保证只覆盖潜心后那一次，若干旱期
一直没掷中潜心则无硬上限。补偿注入额外属性需核算：+5 气血 ×15% ≈ +0.75 HP/级，
L99 累计 +73（基准 1570 的 +5%）——**补偿只给气血不给战斗点**，偏差方向让 TTK
更稳，安全。

**形式二：计数保底（隐形 pity 计时器）**
隐藏计数器记录距上次珍贵掉落的突破次数，到 N（如 3）后下次强制掉珍贵池并清零；
可全局或分类（武器/功法分开计）。最坏情况有硬上限、数值干净，但无叙事感。

**形式三：混合（推荐）**
轮盘保留潜心结果（叙事+补偿+下次必掉），另加宽松全局计数器（连续 4 次无珍贵掉落，
第 5 次必掉）。潜心兜体验感，计数器兜极端坏运气。

| 维度 | 潜心 | 计数保底 | 混合 |
|---|---|---|---|
| 最坏干旱期 | 无硬上限 | ≤N 次 | ≤N 次 |
| 叙事/趣味性 | 强 | 无 | 强 |
| 数值副作用 | 需核算（补气血） | 无 | 需核算 |
| 实现复杂度 | 低 | 低 | 中 |
