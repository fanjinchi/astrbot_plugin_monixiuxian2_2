# 防具设计说明（armors.csv 配套）

> 2026-09-08 定稿框架（openspec change `armor-content-design`，重锚版经用户拍板）。
> 数据表：`armors.csv`（每行一件防具）；机器校验：`validate_budget.py` check_armors；
> 验收模拟：`../attribute-growth/sim_route_matchup.py --loadout`。

## 1. 框架一句话

重甲（护甲主、HP 辅）与法袍（HP 主、护甲辅）在**同品级等效生命（EHP）倍率相等**；
路线向性只通过 route_mult 对称系数表达（标杆批 18 件全通用 1.0，向性件留变体扩展）。

## 2. 供给曲线（D1）

- 品级/门槛与武器完全同一套：凡0/灵11/地21/天31/皇41/帝51/道61/仙71/混元81。
  第一季实装凡~天 8 件；皇品起为**跨季外推**（H 改用中立基准，见 §3）。
- 门槛级总护甲目标：`A = K×r/(1−r)`，K=100+10L，**总口径 = 天生 + 同品级武器 + 本件**。
  重甲目标 r=20%（带 18~22%），法袍目标 r=14%（带 12~16%）。
- 法袍带为什么是 12~16% 而不是原批的 6~10%：武器护甲分品级递增（凡15/灵30/地45/天60…），
  每件武器在门槛级自带 ~12.5% 减伤（既定设计 + 格挡来源），法袍件护甲不可能为负，
  6~10% 数学不可达。重锚后法袍 = 武器基底 12.5% + 袍件小护甲（2026-09-08 用户拍板，
  在 14% 强对比与 ~17% 护甲阶梯可见之间选择了 14%）。
- 单件 armor_value = A − 天生护甲（体修 6 / 灵修 0）− 同品级武器护甲。
  件值曲线：重甲 **7/17/27/37/47/57/67/77/87**（整 +10/品，各门槛级实测 r≈20.0~20.3%）；
  法袍 **3/4/5/7/8/9/11/12/13**（各门槛级实测 r≈13.9~14.1%）。

## 3. 对称 EHP 与 M 序列（D2）

```
EHP 倍率 = (1 + bonus_hp / 基准气血H) / (1 − 减伤率r) = M（两族相等）
bonus_hp = H × (M × (1−r) − 1)
```

- **M 序列**：凡品 1.25、每品 +0.0125、皇品起封顶 1.30 →
  1.25 / 1.2625 / 1.275 / 1.2875 / 1.30×5（v1 缓坡）。M 下限 1.25 由重甲零血量 EHP 锁死
  （1/(1−0.20)=1.25；更低的 M 会使重甲 bonus_hp 为负）。
  原案 +0.025/品、cap 1.35 在带装验收中使 L40 跨路线胜率跌至 47.7%
  （修正模拟器 level_index 桩后仍差 0.3pp），缓坡在保持"装备占比渐升"的前提下
  把 L40 拉回 49.8%（2026-09-08 定）；跨季封顶 1.30 是保守选择，
  后续赛季若放宽 TTK 上限可再抬升。
- **H 取值**：第一季品级（凡~天）取 route-identity 期望面板（重甲按体修 150/319/478/628、
  法袍按灵修 110/261/422/592）；皇品起取中立验算基准 `HP(L)=100+15×(L−1)`
  （700/850/1000/1150/1300，README §3 惯例）。
- 结果 bonus_hp：重甲 **0/3/9/18/27/33/39/45/51**，法袍 **8/23/41/63/83/101/117/136/154**；
  逐品级 EHP 偏差 ≤0.5%（凡品重甲因 b=0 钳制偏差 +0.5%，其余 ≤0.2%），远小于 ±5% 容差。

## 5. 设计纪律与边界

- **属性池**：防具只挂 armor_value / bonus_hp，永不挂身法/迅捷/伤害词条
  （闪避差值轴与迅捷行动经济轴是 route-identity 已校准的敏感平衡轴）。
- **法袍护甲列平缓（3→13）是有意设计**：法袍的品级阶梯在 bonus_hp（+8→+154，19 倍跨度，
  陡于重甲护甲的 12 倍）；文案与商店展示以 HP 为法袍主卖点。
- **减甲交互**：金丹+解锁减甲状态机制（route-identity §4），护甲侧防御被减甲克制、
  HP 侧免疫——两族构成差即"对减甲的抗性差"，属风味级影响，不做数值补偿。
- **格挡**：防具护甲只参与百分比减伤、不计格挡（`separate-block-armor-source` 已落地）；
  总减伤（护甲 + 心法百分比乘算）受 40% 上限约束，本框架两族门槛级合计均远未触及。
- **向性件规则预留**：标杆批全通用；向性件（1.2~1.4 / 0.5~0.7 镜像、奖小于罚）随变体扩展
  引入，届时乘区后总减伤 MUST ≤25%（spec「防具供给曲线」约束）。
