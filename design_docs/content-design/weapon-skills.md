# 武器挂载触发技：v1 技能池设计表

> 2026-08-06。配合 `weapons.md` 标杆件体系，给武器变体扩展提供可挂载的触发技池。
> 选型原则：**只用引擎已支持的效果**（damage_bonus / combo / stun / counter /
> damage_reduction），v1 落地不需要改战斗代码。
> 原型与数值区间依据 `skills-ultimates.md` §2（MB / QPet / researcher 三方素材）。

## 0. 挂载格式（引擎硬约束，务必遵守）

武器条目**绕过 skill_manager 归一化**（`get_battle_loadout` 直接透传），
`trigger_skills_json` 必须使用**引擎键**，用 config 功法那套 `trigger_condition`/`effect`
键会静默失效：

```json
[{"name": "裂空斩", "trigger_timing": "on_attack", "trigger_rate": 0.15,
  "effect_type": "damage_bonus", "effect_value": 0.4}]
```

- `trigger_timing` ∈ `on_attack` / `on_defense` / `on_crit` / `round_start`
- `effect_value` 语义是**加性倍率**：0.4 = 触发时该击 ×1.4；期望增幅 = rate × value
- `counter` 特殊：反击伤害 = **damage 属性 × value**，不吃武器 base_damage/K
  （随境界属性成长，高境界相对变强，value 勿超 1.0）

## 2. 挂载规则（变体扩展时执行）

1. **每件武器至多挂 1 个**；凡品/灵品不挂（新手期保持简单），地品起可挂。
   内容分布目标：地/天品约 30% 变体挂载，皇/帝约 50%，道/仙约 70%，混元先天必挂。
2. **技能强度全品级扁平**：乘性设计自带成长（增幅作用于武器每击），不随品级改数值；
   高品级差异靠**技能池分层**——骤雨式、震魂槌、缚灵符、借力打力限天品（L31+）以上挂载。
3. **强度税 ≤8%**：挂载武器每击期望 = base 每击 ×(1+税)，base_damage 应取预算带
   **中下段**，使含税期望不越过预算带上限 +5%。
4. **与功法独立叠加**：武器技与功法技分别判定、倍率连乘（`total_skill_mult`），
   属预期行为；G2 ≤30% 核算时武器税与功法池**分开计账**。
5. 同武器不进商店展示技能数值细节，描述文案带一句风味即可（如「挥动时偶现裂空之声」）。

## 3. v2 候选（needs_code，待引擎扩展后补充）

呼应 `skills-ultimates.md` §2.2，优先级从高到低：
**饮血**（吸血 heal，10–20%×伤害 15%）、**破势**（必中，克制闪避流）、
**湮灭纹**（真伤/无视 X% 护甲，高境界防拖）、**淬毒**（DOT，依赖持续状态结构）。
免死类不做武器挂载（装死类效果走奥义通道，每场一次才可控）。
