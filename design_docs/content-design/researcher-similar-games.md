# Research：中文文字修仙 / Q宠式自动战斗同类游戏武器/技能/心法设计素材

## Summary
通过对 一念逍遥、想不想修真、无极仙途、修仙家族模拟器、乱斗堂、Q宠大乐斗（后期神器） 等 6 款同类游戏的公开攻略/玩家实测数据深读，整理出一套可直接套用到 AstrBot 修仙插件的「效果类型学（taxonomy）」与数值区间。核心结论是：中文修仙自动战斗的效果框架可归纳为 **伤害/身法/迅捷/气血** 四个维度，主动功法负责触发高倍率或控制，被动心法负责稳定属性/抗性与触发类特效；同类游戏的数值倍率集中在 **1.2x–2.5x 单体、0.5x–1.2x 全体、2.4x–7.6x 多段**，控制概率多落在 **15%–40%**，控制效果通过**冷却、单场次数上限、持续回合数**三者平衡。

## Findings
1. **一念逍遥把战斗属性拆成 8 个系统，暴击与破防有硬上限。** 角色属性包含 攻击、防御、血量、真元、命中、闪避、会心、破防。其中「会心」（暴击）上限为 50%，基础会心倍率 1.5x；「破防」按百分比削减防御；「格挡」触发概率约 30%，触发后降低伤害。控制强度与抗性通过「控制概率强化/控制概率抗性」对抗。 [一念逍遥属性篇](https://www.taptap.cn/moment/372120720546534671)（玩家攻略，置信度：中）

2. **一念逍遥法宝词缀是武器/法宝特效的标准模板。** 攻击类法宝（剑/壶/印）常见后缀为「2 命中 + 3 会心 + 4 伤害/2 时间」或「4 控制概率强化 + 2 控制概率抗性 + 4 时间」。铃铛/镜子类偏向控制概率强化与抗性；古宝附带眩晕、麻痹等特效。这说明装备特效应分伤害/控制/抗性三系。 [一念逍遥法宝词缀](https://www.x6g.com/zixun/17000.html)（攻略站，置信度：中）

3. **想不想修真 4.4 混沌法宝提供了「高等级内容数值预算」范例。** 100+ 混沌法宝分 1–18 品，最多装备 12 件；触发概率多为 10%，效果包括「混沌真伤（初始 10000 真实伤害）」「伤害 +n%」「吸血 +10%」等；炼器师等级与材料决定可用品级。高阶属性来自「熔炼」和「炼器」，说明后期数值成长应依赖百分比而非固定值。 [想不想修真 4.4 混沌法宝](https://www.7723.com/gonglue/103860.html)（攻略站，置信度：中）

4. **想不想修真神界把「速度阈值」作为控制流胜负手。** 神界后期角色速度阈值约 10 万，防御阈值 30–90 万，命中阈值约 10 万；控制类如「灭魂」可使目标眩晕 3 回合，pvp 中谁先出手、命中是否达标直接决定控制链能否生效。 [想不想修真神界攻略](https://www.7723.com/gonglue/103882.html)（攻略站，置信度：中）

5. **无极仙途门派技能展示了「境界门槛 + 星级 + 冷却」的功法结构。** 1–5 星门派按境界解锁；技能伤害系数常见 1.0x，并附加「根骨×2.2」「体魄×2.5」等属性缩放；BUFF 类提升 20%–100% 属性，持续 3–31 回合，冷却 6–10 回合；存在「跳过回合」与「无效果」技能作为负面/占位设计。 [无极仙途门派全解析](https://www.260k.com/gonglue/1719.html)（攻略站，置信度：中）

6. **修仙家族模拟器 2 的 394 条神通数据是最完整的技能 taxonomy。** 神通分为单体/全体/多段/双目标/三目标；单体倍率 0.5x–10x，多段总倍率 2.4x–7.6x；BUFF/DEBUFF 持续 2–4 回合为主，提升幅度 20%–100%（高阶可达 200%）；先手速度、双防、双攻、免伤、暴击率、穿透、命中率等属性均可被技能改变。 [修仙家族模拟器 2 神通测试](https://www.taptap.cn/moment/494624851114328349)（玩家实测，基于 Steam 群策划文档，置信度：高）

7. **乱斗堂技能钥匙体系揭示了自动乱斗的触发概率与副作用设计。** 技能钥匙触发概率 15%–23%；「武神重锤」15% 眩晕 6 秒；「爆裂一击」250% 伤害但下回合疲劳；「疾行术」本场最多提升速度 10 点；「反击」17% 触发并造成 144% 伤害。平衡手段：眩晕带冷却、高倍率带副作用、速度加成设单场上限。 [乱斗堂技能钥匙](https://www.sjwyx.com/luandoutang/jineng/43357.html)（攻略站，置信度：中）

8. **Q宠大乐斗后期神器特效是武器特效的直接蓝本。** 真·关刀 40% 连击；真·充气锤 30% 跳过对手一回合；真·狂魔镰 必中且不会被反击；真·三叉戟 取消攻击后的休息回合；真·铅球 连扔三次；圣器龙蛇弓 降低对方力量 50% 持续 3 回合、部分武器带 30% 吸血。武器升星 0→5 星成功率 100%→60–70%→30–40%→≤15%→≤5%，失败会降级。 [Q宠大乐斗神器终极效果](http://www.xiaozuowen.com.cn/news/z/qqfight/gl/73140.html)（攻略站，置信度：中）

## 效果类型 Taxonomy 表

| 效果类型（子类） | 典型数值 / 触发率 | 来源游戏 | 适配建议（映射到修仙四维 + 功法/心法） |
|---|---|---|---|
| **直接伤害 - 单体** | 倍率 1.2x–2.5x（常见 1.5x） | 修仙家族模拟器、无极仙途 | **伤害** 维度；主动功法/武器普攻触发 |
| **直接伤害 - 全体/AOE** | 倍率 0.5x–1.2x（每目标） | 修仙家族模拟器、无极仙途 | **伤害** 维度；群攻功法，适合破防/清宠 |
| **多段伤害** | 3–10 段，总倍率 2.4x–7.6x，冷却 6–8 回合 | 修仙家族模拟器 | **伤害** + **迅捷**；独立判定暴击/闪避，可触发连击/吸血 |
| **真实/混沌伤害** | 10% 触发概率，固定真伤或按生命百分比 | 想不想修真 | **伤害** 维度；后期被动心法/法宝特效，防高防敌人 |
| **破甲 / 穿透** | 忽视 20%–100% 物防/法防 | 修仙家族模拟器、一念逍遥 | **伤害** 维度；破防功法，克制高防肉盾 |
| **暴击 / 会心** | 暴击率常见 20%–50%，会心倍率 1.5x | 一念逍遥 | **伤害** + **身法**；被动心法堆暴击率，功法触发暴击伤害 |
| **命中 / 闪避** | 闪避加成为基础值乘算；命中率随等级阈值提升 | 一念逍遥、修仙家族模拟器 | **身法** 维度；闪避流心法、命中功法对抗高闪 |
| **先手速度 / 攻击速度** | 提升 20%–100%，冷却 6–8 回合 | 修仙家族模拟器、无极仙途 | **迅捷** 维度；决定出手顺序，可做成境界解锁被动 |
| **连击** | 30%–40% 概率额外攻击一次 | Q宠大乐斗、乱斗堂 | **迅捷** + **身法**；触发式功法或武器特效 |
| **反击** | 17%–100% 触发，反击伤害 144% 或普攻 | 乱斗堂、Q宠大乐斗 | **身法** 维度；被动心法，受击触发 |
| **吸血 / 生命回复** | 10%–30% 伤害吸血，或回复 20%–80% 气血 | 想不想修真、修仙家族模拟器 | **气血** 维度；续航功法/被动心法 |
| **群体治疗** | 群回 20%–50% 气血，冷却 7–8 回合 | 修仙家族模拟器 | **气血** 维度；辅助型功法/心法 |
| **增伤 / 属性 BUFF** | 物攻/法攻/双攻 +20%–200%，持续 3–4 回合 | 修仙家族模拟器、无极仙途 | 主动功法爆发，或常驻被动心法低数值版 |
| **免伤 / 减伤** | 20%–100% 免伤，持续 2–4 回合 | 修仙家族模拟器、一念逍遥 | **气血** + **身法**；防御功法和肉盾被动心法 |
| **控制 - 眩晕/封印** | 触发率 15%–40%，持续 1–3 回合，冷却 6–8 回合 | 想不想修真、乱斗堂、Q宠 | **迅捷** + **身法**；控制功法，需命中/速度门槛 |
| **控制 - 跳过回合/缴械** | 30% 跳过回合、50% 缴械 | Q宠大乐斗 | **身法** + **迅捷**；武器/功法硬控，需限制单场次数 |
| **必中 / 不可反击** | 必中、无视闪避、不可被反击 | Q宠大乐斗、一念逍遥 | 武器特效/稀有被动心法，克制闪避/反击流 |
| **控制强化 / 控制抗性** | 控制概率强化 vs 控制概率抗性 | 一念逍遥 | **身法** 维度；对抗控制链的心法 |
| **持续伤害（毒/流血）** | 触发后每回合掉血，持续 3 回合 | Q宠大乐斗 | **伤害** 维度；DOT 功法，可叠加但需设上限 |
| **负面副作用** | 下回合疲劳/跳过自身回合 | 乱斗堂、修仙家族模拟器 | 平衡高倍率/高控制技能，做成功法代价 |

### 平衡机制速查

| 平衡手段 | 典型做法 | 来源 |
|---|---|---|
| **冷却** | 高倍率/控制技能冷却 6–10 回合 | 修仙家族模拟器、无极仙途 |
| **单场次数上限** | 速度/反击等属性本场最多提升 N 点 | 乱斗堂 |
| **持续回合** | 控制/BUFF 持续 2–4 回合，高阶可达 6 回合 | 修仙家族模拟器、想不想修真 |
| **触发概率上限** | 暴击率 50% 封顶；控制概率 15%–40% | 一念逍遥、乱斗堂 |
| **失败/降级** | 武器升星 4→5 成功率 ≤5%，失败降级 | Q宠大乐斗 |
| **副作用** | 高伤害技能附带自身疲劳、 skip 自身回合 | 乱斗堂、修仙家族模拟器 |
| **属性稀释** | 百分比提升在境界基础值上生效，会被装备稀释 | 修仙家族模拟器 |

## Gaps
- **具体触发率与冷却的完整对应表**：修仙家族模拟器与无极仙途的技能虽给出倍率和持续回合，但并非所有技能都标注触发率与精确冷却，部分标注为「无效果」或「跳过回合」的 BUG 技能难以直接采用。
- **高等级数值预算表**：想不想修真、一念逍遥的后期属性阈值多为玩家经验估算，缺少官方公开的「境界-属性-DPS」预算表。
- **控制效果的递减/免疫机制**：同类游戏大多用冷却和持续回合控制，但**递减（diminishing returns）与受控免疫**的公开机制极少，仅一念逍遥有「控制概率抗性」一项。
- **升星/强化消耗公式**：Q宠大乐斗给出星级成功率，但缺少每次强化消耗的卷轴/材料公式；想不想修真法宝熔炼公式同样未公开。
- **复活、护盾、真实控制链（沉默/封印）** 在修仙类来源中样本较少，主要见于 Idle Heroes，本次未深读，可后续单独补充。
- **官方策划博客/解包数据**：本次来源多为攻略站与玩家论坛，未找到官方策划公开的设计文档或解包数据。

## 建议的下一步
1. 用本 taxonomy 在插件 `config/*.json` 中先建立「效果类型枚举」与「数值区间常量」。
2. 针对控制类功法，设计**触发概率 + 冷却 + 单场次数上限**三条平衡线，避免控制链过强。
3. 对于后期境界（元婴以上），参考想不想修真/一念逍遥的**百分比真实伤害与阈值化命中/速度**，防止高防御导致战斗拖沓。
4. 如需补充复活/护盾/沉默等类型，可单独检索 AFK Arena 中文数据库或《剑与远征》英雄技能表。
