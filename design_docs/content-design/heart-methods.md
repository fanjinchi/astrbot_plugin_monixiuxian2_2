# 心法设计：v1 被动数值 + 修炼加成池

> 2026-08-06。心法 v1 只做**被动数值 + 修炼经验加成**两层（配套功法 `skill_pool`
> 按决策留空，待功法池定稿后回填）。目标：用这两条层做出差异化玩法搭配，
> 并给出低品级 → 高品级的强度区分规则。
> 数值校验：`validate_budget.py` 已检查单条 `_percent` 被动 ≤15%（§4.3 cap）。

## 1. 引擎现状（零代码改动可用的设计空间）

`models.py:get_total_attributes`（item_type=`main_technique` 时生效）：

| 键 | 语义 | 性质 |
|---|---|---|
| `hp_percent` | 总气血 ×(1+v) | 乘算总值，生存端 |
| `damage_percent` | 总伤害 ×(1+v) | 乘算总值，输出端 |
| `agility_percent` | 总身法 ×(1+v) | 闪避端（受闪避 cap 40% 约束，价值递减） |
| `speed_percent` | 总迅捷 ×(1+v) | **出手权**：P(先手)=speed_A/(speed_A+speed_B)，输出+生存**双端**收益 |
| `armor_value` | 护甲平加 | 新公式 armor/(armor+100+10L)，随等级衰减 |

`exp_multiplier`（独立字段，不在 passive_bonus 内）：
修炼经验 ×(1+v)，与灵根倍率、丹药倍率**连乘**（`cultivation_manager:calculate_cultivation_exp`）。
商店与装备界面已会展示「修炼效率+X%」。

`route_multiplier`（JSON 对象，含 `灵修` / `体修` 两个键，缺省均为 1.0）：
按玩家当前修炼路线（`cultivation_type`）选取对应倍率，对 `passive_bonus` 的百分比项与
`armor_value` 平加项进行乘算（`effective_value = value × route_mult`）。
`exp_multiplier` 不受 `route_multiplier` 影响，保持按配置原值生效。

## 2. 差异化：三条设计轴

1. **战斗专精轴**——被动集中在单一属性，形成 build 锚点：
   输出（damage）、坦克（hp+armor）、闪避（agility）、先手（speed）。
2. **修炼效率轴**——exp_multiplier。与战斗被动构成**根本权衡**：
   战斗心法 exp=0，修炼心法战斗点数约为品级预算的 1/4~1/2。
   玩家大方向抉择 = 「苦修速升（时间换强度） vs 战力即得」。
3. **复合程度轴**——品级越高，被动条数越多（单条 cap 15% 锁死，
   高品级只能靠**复合**拉开差距，天然形成品质感）。

### 六种玩法搭配（心法 × 武器/挂载技，见 `weapon-skills.md`）

| 流派 | 心法链（跨品级接力） | 搭配 |
|---|---|---|
| 爆发输出 | 烈火功(L11) → 战神诀(L41) → 乾坤功(L71)/混元一气功(L81) | 重武器 + 崩山击/蓄锐式 |
| 气血坦克 | 长春功(L0) → 龟息功(L11) → 不动明王功(L41) | 减伤/反击挂载 |
| 身法闪避 | 玄影功(L31) → 无我功(L71) | 轻武器 + 疾风刺；受闪避 cap 约束 |
| 迅捷先手 | 疾风迅雷功(L51) | 中/轻武器；出手率 = 双端收益 |
| 苦修速升 | 养气诀(L0) → 云游诀(L21) → 紫府功(L31) → 归一诀(L51) → 万寿诀(L61) → 大梦千秋诀(L81) | 任意；核心资源是时间 |
| 均衡复合 | 金罡诀(L21) → 太虚功(L61) → 混元一气功(L81) | 通用 |

**心法链**概念：低品级心法不是过渡废品，而是同流派跨品级的路径起点——
玩家 L11 选烈火功即宣告爆发流路线，L41 换战神诀是同一流派的升档。

## 3. 品级区分规则

- **战斗点数预算**（品级总强度）：凡 10 / 灵 12 / 地 14 / 天 16 / 皇 18 /
  帝 20 / 道 22 / 仙 24 / 混元 26。
- **点数折算**（v1 假设，待 sim 校准）：hp/damage 1% = 1 点；
  speed 1% = 1 点（双端收益，按主属性计）；agility 1% = 0.7 点（闪避 cap 递减）；
  armor 按门槛级减伤% × 1.1 折算（减伤 10% ≈ 有效气血 +11%）。
- **单条 `_percent` ≤ 15%**（§4.3，validate 强制）→ 高品级必须复合。
- **exp cap**：凡 8% / 灵 10% / 地 15% / 天 20% / 皇 25% / 帝 30% / 道 35% /
  仙 40% / 混元 45%。修炼向心法战斗点数 ≈ 预算的 1/4~1/2（兑换比待校准，见 §5）。
- **route 与 route_multiplier**：`route` 为装备校验字段（决定能否装备），`route_multiplier` 为数值倍率字段（决定被动加成幅度）。v1 池 `route_multiplier` 全部 1.0；v2 路线专属心法可差异化（如灵修向 1.2 / 0.6）。
- **required_level_index**：沿用武器标杆的品级门槛 0/11/21/31/41/51/61/71/81。
- **shop_weight**：100/60/35/20/12/7/4/2/1（相对梯度，与武器池的配比待商店联调）。
