# 世界观设定集（World Bible）：摸鱼修仙界

> **本文档是插件所有内容文案的唯一事实来源**：config 描述字段、历练事件池、敌人命名池、宗门 description、悬赏/秘境文本、后续新增物品与剧情，一律以此为准。
> 规则：与其他设计资料（`current-design-report.md` 等）冲突时，**数值以 current-design-report 为准、叙事以本文档为准**；叙事冲突点反查本文档并回写出处。
> 范围：第一季开放至 **元婴**（Lv40：练气/筑基/金丹/元婴）。化神及以上境界无独立"上界"，后续等级开放 = 灵气复苏推进的时间轴，见第 4 章。

## §0 电梯陈述（全篇之锚）

> 灵力沉寂了不知多少年。仙途断了顶，江湖成了故纸堆，元婴便是凡人能想象的天花板——直到最近，干涸的灵脉开始重新渗出水来。
>
> 你原本是芸芸众生里的一个普通人：皇族、贫民、商人、武林之家，都只是一位过客的旧皮囊。直到某天，一位御风而来的仙子或踏云的白发老翁停在面前，上下打量你一眼，说了句"此子有仙缘"，把你带上了一座叫【清X山】的山。
>
> 你加入一家小宗门，学呼吸吐纳，学会看灵脉、辨灵草、挨妖兽的打——然后宗门在复苏初潮的第一波妖乱里没了。你带着残缺的功课和一身狼狈，成了这方重新沸腾的天地里，一只最普通的散修。

**一句话版本**：灵气枯竭与复苏之交，一个被仙缘捡走又失去宗门庇佑的凡人，如何在这片重新长出来的修炼界里活下去——这是摸鱼修仙界的故事，也是每个玩家的故事。

## 第 1 章 基调与文风

### 1.1 世界观主线（历史时间轴）

三幕结构，全部内容文案都应能对应到这条轴上的一个位置：

```
上古（灵气充沛） ──→ 枯竭期（漫长） ──→ 复苏（现在，玩家入场点） ──→ 未来（复苏推进）
   地仙辈出        │  天花板锁死于元婴     │  灵脉回渗、秘境苏醒、       │  等级随复苏开放
   留下秘境/传承    │  秩序重洗、宗门凋敝、 │  妖兽异动、灵根普遍          │  （非飞升上界）
   诸州旧地多奇观   │  凡人江湖为常态      │  元婴仍是天花板              │
```

- **上古**：灵气充沛，出过地仙大能。如今玩家脚底下踩的秘境（万妖洞、玄冰地宫、上古遗迹）与传承之地，都是这个时代留下的遗产与封印。
- **枯竭期**：灵气断流，修炼天花板被时代压死在"元婴"——练气→筑基→金丹→元婴成为世代相传的常识，元婴=凡界顶点（"元婴老怪"）。资源枯萎，争斗随之升级，**正邪两路性格在此成型**（见 §3）。
- **复苏（现在）**：灵气"涟漪初起"。灵脉回渗、秘境老药重新生长、死于枯竭的灵根重新变得普遍、沉眠的妖兽开始躁动。元婴仍是天花板，但处处是"要重新长出来"的躁动——**也是第一波妖乱、新手宗门被毁的直接原因**。
- **未来**：不设上界。后续境界（化神及以后）在叙事上是**灵气复苏推进后尘封的突破路径重新解锁**，是时间轴的推进，不是空间上的飞升。第一季文案**不为后续季度留钩子**：不需要出现"未开放的上界""化神以上不可见"之类剪影内容，只需遵守"元婴是当下天花板"这一事实。

### 1.2 叙事视角与群聊约束

- 群聊文字游戏，第三人称"**你**"视角；叙述者是"说书人口吻"，允许轻松的旁观语气，但回落在玩家行动上要具体、可想象。
- 所有用户可见输出为**中文**；避免英文单词、避免送术语注释（换算表归设计文档，不进游戏文案）。
- 描述遵循"**动作 → 画面 → 结果**"顺序：一句场景、一句动作、一句结果。单条文案默认 1~3 行。

### 1.3 玩梗尺度（合格 / 不合格对照）

尺度原则：**允许欢乐向门派梗、谐音梗、淡雅的现代梗作"彩蛋位"；禁止出戏的现代词汇进入物品/事件描述正文**。梗放在描述末尾括号彩蛋，或由正经描述先行。

**心法/宗门文案的"正经/不正经"按宗门形象分档**（2026-08-26 定）：本作宗门有正经位（学院派、佛门）与玩梗位（魔道、灰色势力），**心法描述的语气跟着宗门形象走**——正经宗门心法写正经，玩梗宗门心法允许通篇玩梗，但无论哪种都不许现代词汇直入正文、不许承诺数值机制。

| # | 场景 | ✅ 合格 | ❌ 不合格 |
|---|---|---|---|
| 1 | 心法描述（正经宗门） | 青云心典：「心静则云生，云生则剑鸣。」 | 「青云心典：绿色环保，低碳修行，每天十分钟，健康上班好心情。」 |
| 1b | 心法描述（玩梗宗门） | 万毒心经：「万物皆可为毒，毒到深处即为道；门规第一课：先学会分清自己是下毒的还是中毒的。」 | 「万毒心经：毒性+20%，附赠中毒状态，点击就送。」 |
| 2 | 血魔宗宗门介绍（玩梗宗门） | 「血魔宗的传说比宗门本身还老：有人说山门是上古血神的一截断指。门中不养废物，只养狠人——弱肉强食就是门规。但暗算同门者死：明着打，打死活该；暗着来，大家都不会放过你。」 | 「血魔宗，一群没羞没臊的摩托车佬，人见人爱花见花开（doge）。」 |

### 1.4 玩家是谁（开场与出身）

- **出身**：每个新玩家从一批凡人身份中随机抽取一个（皇族、贫民、商人、武林之家等）。出身**纯背景 flavor**——只影响一段自我介绍文案与少量 NPC 称呼，不携带任何初始数值或任务差异（平衡为零风险，新内容填充时不得往来源加数值）。
- **仙缘引入**：一位仙人（巨乳肥臀的冷面仙子 或 白发老翁，风格轻松、不做严肃叙事）看上玩家："你有修仙之姿"，把玩家带上【清X山】（X 随机，清X山是**临时新手场景**，非地图正式地名）。
- **专属新手宗门**：每个玩家有一座专属小宗门，通过新手任务引导了解各玩法机制（修炼、突破、历练、战斗、宗门、丹药、装备等），任务文本与怪物均为入门难度。
- **毁宗脱出**：新手期结束，宗门在**第一波妖乱的冲击下被毁**（兽潮/魔潮冲击），玩家带着残缺功课脱离宗门，成为散修，正式进入开放世界。毁宗既是剧情动机，也是"新手引导期结束"的机械说明。
- 叙事分量：这段开场是"世界观体验卡"，是**框架与世界观用的**——完整专属新手宗门系统（场景、任务链、毁宗演出）已登记 bd `astrbot_plugin_monixiuxian2_2-s6n`，后续制作；bible 只定叙事基调。

### 1.5 双路线叙事（基调，展开见第 4 章）

体修 = "肉身成圣，磨血站得住"；灵修 = "借力打力，花样制胜"。这一点必须贯穿所有内容文案（技能命名语系见 §5.5）。

## 第 2 章 地理

### 2.1 总则

- **州域体系（2026-08-26 定）**：正式设 **六州山河**——云州、沧州、朔州、蛮州、青州、中州（见 §2.2），全部作为**事件发生的地理背景**：历练路线文案、悬赏文本、秘境入口描述、宗门山门方位，一律落在这六个州名上，不再用"这片大陆""东境"式泛称。
- **区域 ≠ 秘境 一一对应不成立（2026-08-26 定）**：现有秘境（青云秘境/落日峡谷/万妖洞/玄冰地宫/上古遗迹/青云剑冢）**仍是示例、尚未铺完**。bible 不要求"一个区域对应一个秘境"——州域与区域是**故事发生地**（可以只用来写历练/悬赏/剧情的背景），秘境是**玩法入口**，两者按内容管线各自扩充，互不绑定。写区域文案时允许该区域暂时没有秘境入口。
- 地貌带"枯竭的烙印 + 复苏的躁动"：旧墟、干涸灵脉、重新渗水的灵泉、复苏中爬出来的新兽。

### 2.2 六州山河（州域清单）

| 州域 | 一句定位 | 代表性区域（示例） | 枯竭→复苏烙印 |
|---|---|---|---|
| 云州 | 中原腹地，正气所钟，青云门山门所在 | 青云山、青云剑冢 | 山腹灵脉曾干涸百年，如今重新渗水，山门老树发新芽 |
| 沧州 | 两山夹峙的血色峡谷地带，过路江湖与低阶猎妖者混居 | 落日峡谷 | 谷底埋着上古战场的残甲，灵气回潮后锈铁重新生出灵光 |
| 朔州 | 北境苦寒之地，冰封千年的上古遗迹 | 玄冰地宫 | 永冻灵脉囤积的存量灵气，复苏前靠它吊命，复苏后是最早"活过来"的秘境 |
| 蛮州 | 南疆十万大山，妖域前哨，中低阶妖兽乐园 | 万妖洞 | 洞深处是上古妖脉封印地，复苏后封印松动，妖物渐次苏醒 |
| 青州 | 东海之滨，渔盐之乡，散修与商队的集散地 | （无秘境，仅叙事背景） | 枯竭期最苦的州，复苏后灵泉从盐井里冒出来 |
| 中州 | 上古战场的残址，地仙大能殒身之地，机缘与凶险并存 | 上古遗迹 | 枯竭期无人敢进，复苏后禁制松动，宝藏重新露出獠牙 |

> **秘境清单（示例，未铺完）**：当前 `rift_config.json` 的条目（青云秘境 L0 / 落日峡谷 L3 / 青云剑冢 L3 青云门专属 / 万妖洞 L6 / 玄冰地宫 L10 / 上古遗迹 L15）为**第一季示例**，文案按上表州域归属书写即可，**不要求一州一秘境、更不要求区域与秘境一比一**。后续内容管线按故事需要把秘境补进对应州域，本表不需因此回改。

### 2.3 妖域（分层的智慧梯度）

妖域不是地图区域，是**野外强度分层**（见 `enemies.json`）。两轴并存：

- **实力层**：低阶 → 中阶 → 高阶 → 顶级。
- **智慧层（逐层开灵智）**：低阶野兽懵懂嗜血 → 中阶初开灵智、懂得偷袭布伏 → 高阶智慧近人、可交流可结仇 → **顶层妖王**（苍龙、墨玉麒麟、火凤之属）拥有完整智慧与远远超出普通妖兽的威能，是当前复苏期"深渊里睁眼的存在"，出场即大事件，不做日常怪。

**传承之地守护者**（守碑灵 / 镇殿战偶 / 传承剑侍）不是妖兽，是灵体与构装造物——上古遗留的守卫，遵循残留的指令，可沟通、可谈判，不进食不讲伦理。文案里不得把它们写成"妖兽变体"。

### 2.4 地理命名风格

地名用**两字 / 三字山水意象**：XX山、XX谷、XX洞、XX宫、XX遗迹、XX冢。州名用**一字州**（云州/沧州/朔州/蛮州/青州/中州），忌用现代地名、忌用英文音译、忌用"之城之域之境"的堆叠式自造词（除非有意拉开气氛）。

## 第 3 章 势力

### 3.1 正邪格局：竞争共存（不是你死我活）

- **第一季允许魔道存在，但魔道是"务实的灰"而非"纯恶的反派"**：拼资源、拼拳头、规矩不同，但都在同一块复苏的大地上讨生活。
- 门派可以"正"也可以"魔"（`alignment` 字段），**同一宗门下的松散规则允许玩家双向流动**——正道可能为资源破例，魔道也有自己的行事底线。
- 世界由四块拼图构成：**五大宗门 + 凡人江湖 + 散修 + 妖域**。凡人江湖是底色（皇族、商人、武林之家都在这层），散修是玩家立身之本（毁宗后玩家即散修）。

### 3.2 第一季宗门规划（五宗，2026-08-26 定）

第一季规划 **五个宗门**（设定层面定稿；config/sect_factions.json 暂未变更——现有青云门/合欢宗仅是功能测试基线，正式宗门配置待后续内容变更落地），bible 为每家规划宗门绑定"路线取向 + 玩法幻想 + 文风档位（正经/玩梗）"，内容作者写心法/宗门文案时按表取调：

| 宗门 | 立场 | 路线取向 | 玩法幻想（拜入此宗体验什么） | 文风档位 |
|---|---|---|---|---|
| 青云门 | 正 | 通修学院 | 两条路线全套资源，正经拜师、学系统功课 | 正经学院派 |
| 金刚寺 | 正 | 体修向 | 肉身成圣、金刚不坏，挨打反震流 | 正经佛偈 |
| 天机阁 | 中 | 灵修向 | 观星望气、符箓炼金，术数机关流 | 正经中带冷幽默 |
| 万毒门 | 魔 | 灵修向偏门 | 以毒入道、蛊虫为伴，上毒叠 dot 流 | 玩梗灰（黑色幽默） |
| 血魔宗 | 魔 | 体修向偏门 | 以血炼体、以杀证道，燃血换战力 | 玩梗灰（狂放） |

> 五宗为**设定规划**，其内容位（宗门技能池 `sect_qingyun/sect_jingang/sect_tianji/sect_wandu/sect_xuemo`、镇派心法、宗门之宝、师承链）列在 §6.1 作落地清单；现有 config 的技能池/心法/链名只是功能测试基线，正式内容按 §6.1 的规划位替换。

#### 3.2.1 青云门（正 / 通修学院）

- 定位：正统学院派，占着灵气最好的山头，讲规矩、论资排辈、有洞天有丹房有剑冢。
- 史实：上古遗留的洞府与剑冢收归己有，枯竭期靠遗产与井然秩序活下来的"守成者"；复苏期是它重新扩张的窗口。
- 关键句（用于文案定调）：「青云门讲的是'走对路'，路先于人多问一句为何。」
- 人物：长老玄诚子（传功长老）、清微道长（执事长老）；掌门云游在外（留白，不设具体人格，后续内容可填）。

#### 3.2.2 金刚寺（正 / 佛门体修）

- 定位：佛门体修。寺中僧人讲究"肉身即佛"，不练法术只炼筋骨——铜皮铁骨，金刚不坏。枯竭期里灵脉断流，金刚寺靠人人一身铁打的皮囊活了下来。
- 玩法幻想：挨打反震、金刚不坏，体修玩家的"正派归宿"；心法走正经佛偈风（如镇派《金刚不坏经》："身是菩提树，心是金刚台，皮肉骨血，皆是薪柴"）。
- 关键句：「挨得住打，才配谈慈悲。」
- 人物：方丈玄渡、戒律堂执事净持（掌门即方丈，不设云游留白）。

#### 3.2.3 天机阁（中 / 术数机关）

- 定位：占着云州城外一座八角高楼的术数机构，主修观星望气、符箓炼金——望气看风水，八卦断吉凶，偶尔替朝廷和江湖干点"帮忙看看"的买卖。正邪之间的"技术流"。
- 玩法幻想：灵修玩家的"烧脑派"选择，用符箓/机制/连击花样制胜；文风正经中带冷幽默（"卦象不骗人，骗人的是人"）。
- 关键句：「天机不可泄，泄了要挨雷劈。」
- 人物：阁主顾望舒、观星台执事裴青萝。

#### 3.2.4 万毒门（魔 / 毒蛊实用派）

- 定位：藏在一座终年瘴气不散的山谷里的灰魔道。枯竭期活下来的答案：正道抢仙草，我们抢虫豸；仙草绝了种，虫豸还活着。门中不讲正邪，只讲"活下来的人是对的"。
- 玩法幻想：以毒入道、蛊虫为伴，叠毒 dot 的灵修偏门流；文风走**玩梗灰（黑色幽默）**——心法描述可以通篇玩梗（镇派《万毒心经》："万物皆可为毒……门规第一课：先学会分清自己是下毒的还是中毒的"）。
- 关键句：「活下来的人是对的。」
- 人物：门主毒无涯、蛊堂长老蝎娘子。
- **合欢宗生态位交接（2026-08-26 定）**：原合欢宗的"灰色实用主义 + 带艺投宗 + 玩梗灰"生态位由万毒门承接；合欢宗本体**延后出场**，待双修功能扩展后再正式作为宗门回归（见 §3.3）。

#### 3.2.5 血魔宗（魔 / 血炼体修）

- 定位：山门传说比宗门本身还老（有人说山门是上古血神的一截断指）。门中不养废物只养狠人——以血养身、以杀证道，弱肉强食就是门规；但暗算同门者死，明着打打死活该，暗着来大家都不放过你。
- 玩法幻想：体修玩家的"魔道归宿"，燃血换战力、血影掠杀；文风走**玩梗灰（狂放）**，心法描述允许野味玩梗（镇派《血煞功》："血是柴，一身血肉皆可作薪；烧完了？烧完了就换个更旺的"）。
- 关键句：「血是柴，骨是灶，烧出个横的来。」
- 人物：宗主血屠、血池护法孔无常。

### 3.3 合欢宗（延后宗门，2026-08-26 定）

- **设定上第一季不实装、不作为主要出场宗门**：合欢宗从第一季五宗阵容中移出，等**双修功能扩展**（现有双修指令只做定额修为收益，尚未有宗门级双修玩法）后再正式作为宗门回归。
- **保留的精神遗产**：合欢宗曾是灰色实用主义与玩梗灰的代表（没有山门、随灵脉迁徙、带艺投宗、道法不懂礼数）——这段人设先交给万毒门承接（§3.2.4），回归时再走"双修主题宗门"路线（合籍双修的资源/战斗向玩法），不与万毒门撞型。
- 设定状态：`sect_factions.json` 现有 huanxi 条目是功能测试基线，**不在第一季剧情与玩法中出场**；回归时以新宗门身份重建（含宗门心法、技能池、师承链、专属双修玩法）。

### 3.4 宗门——路线取向绑定规则（新增宗门的硬约束）

第一季规划五宗（§3.2），bible 定规则如下，后续内容变更往**延后位**填（合欢宗）或按需新增（需走内容变更）:

## 第 4 章 修炼体系叙事化

### 4.1 双词汇表（境界名双轨）

力量来源两条路，**境界名各自成表**，文案与日志据此选择词汇：

- **灵修**（借法御灵）：练气 → 筑基 → 金丹 → 元婴（第一季四境；后续随复苏推进解锁化神等）。
- **体修**（肉身成圣）：锻体 → 铜皮 → 铁骨 → 钢筋 → 玄体 → 金刚 → 不灭 → 神体 → 肉身成圣 → 地仙体魄（`body_level_config.json` 十境，max_level 同练 99，第一季玩家按 Lv 落在对应段位上）。

> 设计说明：两表并存的代码背书见 `config_manager.py:383-387`（`_build_level_data(body_level_config, "体修")`）。文案里体修玩家被问到境界时，说"铸就玄体""炼到金刚了"，不是说"你金丹了"。

### 4.2 为什么双路线（世界观解释，直接背书数值）

- **枯竭期练灵修 = 没米下锅**：灵修真元靠吞吐天地灵气，枯竭期灵气断流，灵修只能靠存量灵物吊命，进展极慢、战力贫弱。
- **体修之道不假外物**：体修用气血锤打肉身，血气生于自身，枯竭再狠也断不了这口饭。所以体修在死寂时代活得更扎实——**开局体修气血厚、出手更狠**（初始伤害 15-30 / 气血 120-180 / 护甲 3-10，见 `current-design-report.md`）。
- **复苏是灵修的春天**：灵气回来了，借法御灵的路数开始兑现；灵修身法轻盈、出手迅捷、靠术法机制（控制/连击/必杀）取胜（初始伤害 8-18 / 迅捷 5-15）。**成长后期追平、同级面板差距个位数百分比**——世界给灵修的补偿是"时代终于轮到他们了"。

### 4.3 境界的叙事含义（每境一句）

- **练气**：刚摸到气，丹田里有了第一缕暖意——"通脉即入门，凡人见真我。"
- **筑基**：气沉为基、灵根归位——"根基立，大道始有可称之处。"
- **金丹**：精气神凝成一颗丹——"凡躯藏真火，此生不再空转。"
- **元婴**：丹破婴出、神游千里——"元婴老怪，凡界之巅；再往上，便不是这片天地的说法了。"

（化神起不写——第一季不涉及，见 §1.1 未来段。）

### 4.4 寿元 / 突破失败 / 身死道消

- **寿元**：境界越高，寿元越是"翻出凡人的账本"。**叙事上不再区分"体修短寿"**（2026-08-26 定）——现存代码中体修初始寿命 50-100 是旧五属性框架的历史遗留（无消费点：无寿命耗尽死亡判定、玩家面板不展示寿命），bible 不收编"燃烧精血催动短寿"这套叙事，避免文案承诺不存在的机制；现有寿命数值如何处置属后续内容/数值变更，不在本设定修订内。
- **突破失败**：不是弹一个"失败 -25%"，而是叙事化的凶险——心魔、器劫、天罚，失败轻则修为倒退，重则**身死道消**。文案必须给失败一条"留命"出路（护体法宝、同门护法、机缘侥幸），保证玩家不因突破文案被宣判死刑（数值层仍走 `success_rates` 与 `failure_penalty`）。
- **死生观**：修仙不是养老，文案基调是"每一步都是拿命在试"。

### 5.3 禁用词清单

- **现代/出戏词**：系统、等级、属性、装备、技能、buff、debuff、CD、mmo、氪金、充值、抽卡、数值、本体、目标、冷却、经验、任务完成度……（这些词只存在于策划文档与 UI 之外，不进入游戏文案。）
- **超规格词**：在天品武器上写"最强/无敌/唯一"；在描述里承诺机制（"+30% 伤害""免疫伤害"这类数值表述不得进文案）。
- **重复堆叠词**：不出现"XX仙尊大帝古神修罗狱"这种连缀式称号（单个可用，连缀禁用）。
- **错位伦理词**：正文不出现现代梗（传承彩蛋位除外，见 §1.3）。

### 5.4 一物一名

同一物品**始终用同一个名字**，绝不为了文采另起别名；文案引物名一律用 config 里的正式名（后续加别名需收编进 §6 清单并同步 config）。

### 5.5 双路线语系指引（D3 落地）

体修内容名偏：**肉身 / 气血 / 山岳 / 金刚 / 铁骨**语系；灵修内容名偏：**符箓 / 飞剑 / 借法 / 罡风 / 紫霄**语系；通用件可用中性天地自然词（混元/玄武/真龙）。新建内容时按此三分。
