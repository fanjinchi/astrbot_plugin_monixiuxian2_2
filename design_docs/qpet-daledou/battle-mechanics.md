# Q宠大乐斗早期版本：战斗机制详解

> 对应主简报 `research-notes.md` 第 3 节。聚焦 2010–2012 年核心战斗规则。

---

## 1. 战斗流程（全自动回合制）

1. 玩家选择对手后，进入战斗场景；双方宠物自动进行回合制攻击。
2. 每回合根据**速度**决定该回合内双方攻击次数的分配。
3. 攻击时随机选择“空手攻击”或“已拥有武器”进行攻击。
4. 每次攻击有一定概率触发**主动技能**或**被动反击/连击/控制**。
5. 生命先归零的一方失败；若触发“装死”，可保留 1 点生命继续战斗。

> 来源：腾讯官方新手指引（2011-12）指出“速度决定普通攻击次数”；虹墨空间站（2011-01）描述实战中速度差决定连击频率。 [^1][^3]

---

## 2. 出手顺序与速度

### 2.1 速度对出手次数的影响

- 速度是**相对值**，体现为双方速度比值带来的攻击次数差异。
- 玩家经验：
  - 20 速度 vs 10 速度：高速方可能连打 2–3 次，低速方才出手 1 次。
  - 40 速度 vs 30 速度：差距缩小，出手次数接近 4:3。
- 因此速度在前期（属性较低时）对胜率影响极大，后期边际收益递减。

> 来源：虹墨空间站（2011-01-01） [^3]

### 2.2 追加出手机制

除速度外，以下因素可增加单方攻击次数：

| 来源 | 效果 |
|---|---|
| **无影手**（被动） | 20% 概率触发连续攻击。 |
| **残影**（主动/状态） | 基础速度提高 50%，所有伤害提高 10%（部分资料写 30%），持续 2–3 回合。 |
| **小型武器连击** | 小型武器高概率连续攻击两次（真·流星球可连扔 3 次）。 |
| **红缨枪/真·红缨枪** | 10% / 20% 连续攻击。 |
| **真·关刀** | 40% 连击几率。 |

> 来源：聚侠被动技能介绍（2011-07-19） [^6]；聚侠武器升级介绍（2011-07-19） [^7]

## 3. 伤害计算

### 3.1 玩家推导的简化公式

```
实际伤害 ≈ 武器基础伤害 × 力量系数 × 技能加成 × 状态加成 × 魂珠/暴击加成 × 帮派技能加成 − 防御减伤
```

> 来源：40407《q宠大乐斗武器打出伤害的技巧》（2013-11） [^5]

### 3.2 各项因子说明

#### 武器基础伤害

- 每把武器有一个伤害范围（如 青龙戟 15–20、三叉戟 25–50）。
- 空手攻击时也有基础伤害，与力量相关。

#### 力量系数

- 玩家社区推测：**力量值 ÷ 10** 左右。
- 例：力量 30 时，力量系数约为 3，对空手/武器伤害均有加成。
- **未证实**：官方未公开精确公式。

#### 技能加成

| 技能 | 加成效果 |
|---|---|
| **武器好手** | 武器伤害 +20%。 |
| **惯用重物** | 大型武器伤害 +10%。 |
| **避重就轻** | 中小型武器伤害 +15%（30 级以上可领悟）。 |
| **肉搏好手/武术好手** | 空手伤害 +20%。 |
| **易筋经** | 主动技能伤害 +20%（40 级后可领悟）。 |

#### 状态加成

| 状态 | 效果 |
|---|---|
| **怒了** | 伤害 +50%。 |
| **残影** | 伤害 +10%（早期）/ +30%（后期资料）。 |
| **状态大好** | 属性临时提升（如力量 +2 等）。 |

#### 魂珠/暴击加成

- **帅魂**：暴击时伤害 ×1.5。
- **剑魂**：按等级增加攻击力。
- **武器自身暴击率**：某些武器有高暴击率，可触发 1.5 倍伤害。

#### 帮派技能加成

- **天马流星拳**：触发时伤害 +100%。
- **会心一击**：+50% 伤害。
- **化骨绵掌**：会心一击基础上再 +50%。
- 注：这些帮派技能在 2012 年后资料中常见，2011 年是否全部存在待进一步考证。

### 3.3 防御减伤

| 技能 | 减伤效果 |
|---|---|
| **皮糙肉厚** | 减少所受 20% 伤害。 |
| **霸气护体** | 2 次机会格挡 50% 伤害。 |
| **情比金坚** | 夫妻技能，按亲密度/等级提供百分比减伤。 |
| **大海无量** | 反弹所受 100% 伤害（非减伤，但可视为防守反击）。 |

> 注意：暴击通常忽略“皮糙肉厚”与帮派修炼减伤，但不忽略“情比金坚”和“霸气护体”。 [^5]

## 4. 命中与闪避

### 4.1 闪避来源

| 来源 | 效果 |
|---|---|
| **敏捷基础值** | 决定基础闪避概率，具体公式未公开。 |
| **身手敏捷** | 提高敏捷属性，间接提高闪避。 |
| **凌波微步** | +7% 闪避率。 |
| **灵活步伐** | 增加闪避率（早期资料提及）。 |
| **武器特效** | 如 青龙戟 +10% 闪避、铁铲 +20% 闪避等。 |

### 4.2 命中来源

| 来源 | 效果 |
|---|---|
| **修心术** | 主动技能命中 +3%（可升级，5 星 +10%）。 |
| **菜菜魂珠** | 提高命中。 |
| **必中武器** | 狂魔镰、倚天剑、部分圣器“必中”。 |

## 5. 控制与特殊效果

### 5.1 跳过/限制对手回合

| 技能/武器 | 效果 |
|---|---|
| **企鹅吼** | 造成 15 点伤害，跳过对方 1 回合（可闪避）。 |
| **真·企鹅吼** | 造成 35 点伤害，跳过对方 2 回合。 |
| **充气锤子** | 10% 概率忽略对手 1 回合。 |
| **真·充气锤子** | 30% 概率忽略对手 1 回合，忽略大海无量。 |
| **幻影枪 / 真·幻影枪** | 不会被反击；真·忽略对手 1 回合。 |
| **折凳** | 30 级后可领悟，忽略对手 2 回合。 |
| **胶水** | 10% 概率黏住对方 3 回合，被黏住时仍可闪避。 |

### 5.2 反击

| 技能/武器 | 效果 |
|---|---|
| **第六感** | 30% 概率被攻击后反击。 |
| **真·双截棍** | 对手近身攻击必反击。 |
| **青龙戟 / 板砖 / 平底锅 等** | 一定概率闪避反击。 |

### 5.3 持续伤害

| 技能/武器 | 效果 |
|---|---|
| **企鹅挠痒** | 对方每回合损失 5 + 敏捷×0.2 点生命，持续 6 回合。 |
| **青龙戟（真）** | 50% 闪避反击，带毒持续掉血。 |

### 5.4 恢复

| 技能 | 效果 |
|---|---|
| **矿泉水** | 恢复 25% 生命值（至少 25 点），立即攻击，不跳过回合；可多次使用（具体上限未证实）。 |
| **真·圣水** | 生命值全恢复，消除持续扣血效果，立即攻击。 |
| **师傅驾到** | 恢复 20% 生命，下次攻击必中（10 级且有师傅）。 |

### 5.5 秒杀与锁血

| 技能 | 效果 |
|---|---|
| **神来一击** | 5%–8% 概率将对方生命值降至 1（可闪避）。 |
| **势如暴雨** | 连续投掷最多 3 把武器攻击对手，可躲避（同时躲避所有）。 |
| **如来神掌** | 打掉对方一半血，无视大海无量（QQ 会员专属或 30 级可学会）。 |
| **装死** | 受到致死伤害时有机会保留 1 点血继续战斗；木剑、橡皮擦可无视装死。 |

## 6. 战斗设计参考点

1. **全自动 + 高随机事件** = 观看性强、结果不可预测，适合文字战报展示。
2. **速度决定攻击频率** = 简单属性即可产生“连击”“压制”等戏剧化描述。
3. **闪避/暴击/控制/装死** = 给低战力玩家翻盘机会，避免纯数值碾压。
4. **属性技能 + 被动 + 主动概率技** 三层技能体系 = 成长深度足够但规则不复杂。
5. **反击与连击** = 可在文字战斗中插入“对手攻击 → 你闪避并反击 → 触发无影手连击”等叙事链。
