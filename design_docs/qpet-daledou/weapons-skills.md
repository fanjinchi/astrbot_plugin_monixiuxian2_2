# Q宠大乐斗早期版本：武器与技能详解

> 对应主简报 `research-notes.md` 第 4 节。聚焦 2010–2012 年核心武器/技能体系，后期圣器、觉醒、百炼钢等系统仅作边界标注。

---

## 1. 武器系统

### 1.1 武器获取

- **主要来源**：角色升级时随机获得。
- **触发逻辑**：每次升级若未进入“潜心”状态，则随机获得 **1 把武器** 或 **1 个技能**。
- **后期补充**：活动礼包、商城、挑战 BOSS 等也会产出特殊武器（如倚天剑、圣器）。

### 1.2 武器分类

| 类型 | 攻击方式 | 连击特点 | 代表武器 |
|---|---|---|---|
| **小型武器** | 近程 + 投掷 | 高概率连续攻击 2 次 | 接力棒、平底锅、短剑、流星球、木剑 |
| **中型武器** | 近身 + 投掷 | 连击概率中等 | 红缨枪、板砖、宽刃剑、双截棍、铁铲、环扣刀 |
| **大型武器** | 近身攻击为主 | 低概率连击，单次伤害高 | 青龙戟、三叉戟、充气锤子、关刀、狂魔镰、幻影枪、棒球棒、木槌、开山斧 |

> 来源：牛顿中文百科 Q宠大乐斗词条 [^8]；各 2011 攻略站武器大全。

### 1.3 武器品质与升星

- **普通武器**：初始获得的武器。
- **神器**：普通武器使用“黄金卷轴”升至 **5 星**后变为“真·XX”神器，获得强力特效。
- **凡器 / 灵器 / 仙器 / 神器**：玩家社区对武器强度的非官方分层。

### 1.4 黄金卷轴升星概率（2011 年资料）

| 阶段 | 成功率 | 消耗卷轴 | 风险 |
|---|---|---|---|
| 0→1 | 100% | 1 | 无 |
| 1→2 | 60%–70% | 2 | 无 |
| 2→3 | 30%–40% | 3 | 无 |
| 3→4 | ≤15% | 未知 | 20% 概率降级到 2 |
| 4→5 | ≤5% | 5 | 15% 概率降级到 3 |

> 来源：聚侠《Q宠大乐斗武器升级介绍》（2011-07-19） [^7]

### 1.5 武器入魂（魂珠系统）

- **上线时间**：约在 2011 年前后，属早期强化体系。
- **规则**：每把武器可镶嵌 2 颗（后期资料称 3 颗）不同类型魂珠；入魂 100% 成功。
- **魂珠类型**：菜菜（命中/闪避）、剑君（攻击）、帅帅（暴击）、月璇、月影、血灵、教主 等。
- **魂珠等级**：1–7 级，低级可合成高级，越高级成功率越低。

> 来源：腾讯官方新手指引（2011-12） [^1]；百度百科“魂珠”词条 [^13]

## 2. 技能系统

### 2.1 技能获取

- 与武器相同，**升级时随机获得**。
- 每次升级若未获得武器，则获得技能；反之亦然（潜心状态除外）。
- 部分技能有等级门槛：如 避重就轻 30 级、易筋经 40 级、折凳 30 级。

### 2.2 技能分类

| 类型 | 说明 | 代表技能 |
|---|---|---|
| **属性被动** | 永久提升基础属性 | 天生大力、身手敏捷、快人一步、强健身躯、均衡发展 |
| **战斗被动** | 战斗中概率触发或常驻效果 | 武器好手、肉搏好手、皮糙肉厚、凌波微步、惯用重物、装死、大海无量、霸气护体、第六感、无影手 |
| **主动概率技** | 战斗中自动概率释放 | 晴天霹雳、龙卷风、神来一击、胶水、企鹅吼、势如暴雨、矿泉水、天使之翼、天旋地转、蓄力一击、企鹅挠痒、缴械、残影 |
| **特殊/R技** | 低概率高收益或专属 | 黑龙波（粉钻/黄钻专属）、如来神掌（会员/30 级） |
| **夫妻/帮派技能** | 社交系统附带 | 情比金坚、会心一击、暗器高手、生命音符、天马流星拳、武器禁锢 |

### 2.3 属性被动技能

| 技能 | 效果 | 备注 |
|---|---|---|
| **天生大力** | 提升力量；加成公式 ≈ 基础力量÷2 取整 +3 | 对“龙卷风/天旋地转/蓄力一击/佛山无影脚/木槌”有伤害加成 |
| **身手敏捷** | 提升敏捷；加成公式同上 | 对“企鹅挠痒、天使之翼”有伤害加成 |
| **快人一步** | 提升速度；加成公式同上 | 对“冲锋、疾风步”有伤害加成 |
| **强健身躯** | 提升生命值 | — |
| **均衡发展** | 提升力量、敏捷、速度（除生命外各加成） | 加成公式 ≈ 基础值÷5 取整 +1 |

> 来源：聚侠《Q宠大乐斗技能加成计算》（2011-07-19） [^2]

### 2.4 战斗被动技能

| 技能 | 效果 | 玩家评价 |
|---|---|---|
| **武器好手** | 武器伤害 +20% | 稳定强力 |
| **肉搏好手/武术好手** | 空手伤害 +20% | 前期有用，后期武器多后价值下降 |
| **皮糙肉厚** | 减少所受 20% 伤害 | 稳定但收益中等 |
| **凌波微步** | +7% 闪避率 | 配合高敏捷有效 |
| **惯用重物** | 大型武器伤害 +10% | 配合高伤武器收益高 |
| **装死** | 致死时有机会保留 1 点血 | 玩家公认“第一神技” |
| **大海无量** | 反弹所受 100% 伤害 | 翻盘神技，被皮糙肉厚减伤影响 |

> 来源：聚侠被动技能介绍（2011-07-19） [^6]

## 3. 武器与技能设计参考点

1. **随机获取 + 固定池**：玩家每次升级像抽卡，但池子固定、品质梯度清晰，容易形成社区共识（“神技”“废技”）。
2. **武器类型三角**：小型高连击、中型均衡、大型高伤害，让不同属性流派有偏好。
3. **神器升级风险**：5 星高回报 + 低成功率 + 降级惩罚，是早期页游经典付费与话题设计。
4. **技能分层明确**：属性技稳定提升；被动技改变战斗节奏；主动技概率释放制造高光；RP 技/秒杀技提供传播素材。
5. **克制关系**：木剑/橡皮擦克制装死、大海无量克制神来一击、粉钻黑龙波前期压制，形成简单但有效的策略循环。
