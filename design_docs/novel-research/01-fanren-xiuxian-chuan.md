# 《凡人修仙传》设定与剧情设计笔记

> 类型：凡人流（鼻祖） | 作者：忘语 | 连载：2008 年起，起点中文网
> 创作背景：作者因厌倦当时流行的"蛮荒流"（盘古开天题材）而创作，受《蜀山剑侠传》《聊斋》《西游记》《镜花缘》影响，文风古色古香。开创"凡人流"流派。

## 一、世界观设定

### 1. 境界体系（本书最经典的设定骨架）

三界结构：**人界 → 灵界 → 仙界**，修士通过飞升进入上层世界，每一层世界的灵气浓度与力量上限递升。

- **下境界（人界）**：炼气（13 层）→ 筑基 → 结丹 → 元婴 → 化神
- **中境界（灵界）**：炼虚 → 合体 → 大乘
- **上境界（仙界）**：真仙 → 金仙 → 太乙 → 大罗 → 道祖（每境分初中后期+大圆满）

境界特征（人界篇）：
- 炼气期：共 13 层，寿元与凡人无异，靠灵根吸纳灵气、洗髓易经
- 筑基期：服筑基丹突破，寿元增至 200 岁，宗门中坚（天赋好者闭关冲击金丹，平庸者任执事）
- 金丹期：可炼本命法宝，寿元 500 岁，中小门派高层；乱星海中开宗立派的最低门槛
- 元婴期：肉身被毁可元婴出窍夺舍（保命底牌），人间至尊级别
- 化神期：人界巅峰，需渡天劫，之后可飞升灵界

### 2. 灵根体系（资质设定范本）

- 无灵根者无法修炼（不能吸收灵气、不能用法术法宝、寿元不增）；可借秘法与天材地宝生成后天灵根，概率极低、风险极高
- 五行灵根：金木水火土，对应五行灵气
- **伪灵根**：4-5 种属性（如韩立四灵根），吸收灵气驳杂，正常情况一辈子卡在炼气三四层，筑基无望
- **真灵根**：2-3 种属性，普通修士；十个炼气出一个筑基，百个筑基难有一个结丹
- **天灵根**：单一属性，修炼几乎无障碍，筑基结丹轻松，是各大宗门争抢的对象（每收一个等于多一个结丹修士）
- 设定巧思：**多灵根在化神突破炼虚时需要"五行合一"，此时灵根越多反而越难**——低资质在后期变成独特优势，形成"废柴逆袭"的合法化机制
- 灵根衍生：体质、灵脉、血脉等与灵根并列的资质维度

### 3. 势力与地理（金字塔式世界结构）

- 天南修仙界：黄枫谷、落云宗、掩月宗、太真门、化意门、合欢宗（T3 级）
- 人界势力分级（T0-T9）：太一门、天魔宗、万妖谷为 T0（保底 1 位化神 + 4-5 位元婴后期，元婴总数 50+）；星宫、逆星盟、小极宫 T1；大晋正魔十大宗门、叶家、乱星海妖族 T2
- 地图弧线：小山村（七玄门所在）→ 黄枫谷 → 乱星海 → 天南 → 大晋 → 灵界 → 仙界，**每次换图 = 力量天花板升级 + 全新势力生态**

### 4. 资源设定（凡人流的灵魂）

- 灵石为货币；丹药（筑基丹、结婴丹等）是突破瓶颈的关键资源；灵药、灵矿、秘境产出有限
- 弱化型金手指：**小绿瓶**——催熟灵药，不直接给力量，只给"资源生产效率"，避免无脑爽
- 上古历史设定：上古大能与域外古魔大战 → 大量强者陨落/飞升，古魔被封印在各禁地，灵气浓度急剧下降 → 中古时代门派制度兴起（资源共享、传承延续）→ 今世修仙界。**"上古大战 → 灵气枯竭 → 门派制度"的因果链解释了世界观现状**

## 二、主角与剧情主线

主角韩立：山村穷小子（为让家人吃饱饭投考七玄门）→ 被墨大夫收为药童 → 靠小绿瓶催熟灵药 + 谨慎算计一路进阶：七玄门 → 黄枫谷（灵药园管事）→ 血色试炼 → 乱星海 → 天南大战（魔道入侵）→ 灵界 → 仙界。

- 人界篇叙事弧：慢热开局（大量日常笔墨，写实基调）→ 探索式推进（低阶修士视角与读者同步了解世界）→ 主动介入格局（天南大战串联数十个此前零散的角色与势力）
- 天南大战的叙事技巧：**并非突然爆发，而是通过前期数百章逐步铺垫**（魔道入侵线牵引零散势力汇聚）

## 三、设计亮点（凡人流范式）

1. **仙凡二元结构**：仙人起点回归凡人，"凡人修仙"的价值根基是"做大事之前先吃饱饭""借了东西一定要还""事来了不要怕，没事也别去惹事"——朴素凡人信条 vs 世家子弟修仙
2. **金字塔式等级 + 资源达尔文主义**：世界框架严谨，从塔底到塔尖越爬越难；资源有限且极端重要；修仙不再是精神超脱，而是唯物主义的资源竞争
3. **智商在线的配角与主角**：配角不降智（雷姓修士等），主角藏锋守拙、谋定后动、谨慎自控；情感上对亲情友情疏离克制（"韩老魔"绰号来源）
4. **弱化金手指**：只加速资源获取，不改变资质差距本身，保留成长的真实感
5. **"人味"叙事**：实力强大后依然保留凡人心态与日常细节，形成与神仙剧的差异化

## 四、对本游戏（文字修仙）的可借鉴点

- **境界名与层数结构可直接采用**：炼气13层 → 筑基/结丹/元婴/化神（每境初中后期+大圆满）→ 炼虚/合体/大乘 → 渡劫飞升，是玩家认知度最高的修仙境界序列
- **资质设定**：灵根（伪/真/天灵根）可作为角色创建的随机资质维度，影响修炼速度与瓶颈；"低资质后期反而有五行合一优势"是"废柴流"留存的合法性设计
- **资源驱动循环**：灵石 + 丹药（突破用） + 秘境/副本 + 宗门贡献，形成"打工→买资源→突破→换地图"循环
- **换图升级结构**：每个新区域 = 更高天花板 + 新势力 + 新资源，天然适合做成游戏的不同"大陆/副本群"
- **事件模板**：血色试炼（宗门内选拔试炼）、乱星海（自由海域争夺）、天南大战（多方势力混战）、上古遗迹探索（揭示世界历史）
- **文本风格**：古色古香、克制写实，突破描写强调"资源准备充分 + 水到渠成"而非一蹴而就
