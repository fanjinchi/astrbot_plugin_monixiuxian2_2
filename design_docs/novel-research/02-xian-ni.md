# 《仙逆》设定与剧情设计笔记

> 类型：逆天流 / 凡人流变体 | 作者：耳根 | 连载：2008-2013，起点中文网
> 核心口号："顺为凡，逆则仙，只在心中一念间"。2023 年改编动画成为现象级国漫。

## 一、世界观设定

### 1. 境界体系（修真三步）

- **第一步（修真基础）**：凝气 → 筑基 → 结丹 → 元婴 → 化神 → 婴变 → 问鼎（= 阴虚/阳实，即"四圣"中的问鼎期）→ 过渡期
- **第二步（仙界层次）**：窥涅（触摸规则，天仙级）→ 净涅（掌握规则，仙王级）→ 碎涅（完全掌握并创造神通，天君级）→ 天人五衰（九品，需度过"三陨七劫"）→ 破空（仙帝）
- **第三步（空之四境）**：空涅（元力变涅力）→ 空灵（开辟内天地）→ 空玄（言出法随）→ 空劫（九次玄劫洗礼）→ 半步踏天 → 踏天（无所不能，可复活他人）

跨体系对照：仙遗族一叶~四叶对应凝气~元婴；妖灵 1甲妖=凝气一层、百甲妖将=元婴、十万甲妖将=婴变；古神战力对标（一星古神=3000-5000 灵压）。

### 2. 核心设定："欲化神，先化凡"

- **化神期是分水岭**：从灵力运用上升到"天地规则 + 人生感悟"层面。元婴突破化神**必须体悟出一种意境**，与元婴融合形成元神，元神不灭则灵魂不亡
- **化凡**：元婴修士要化神，必须先"化凡"——变回普通人体验凡人生老病死，于平淡中感悟大道。王林经历**三次化凡**（生死化凡-木匠、梦道化凡-书生等），感悟出生死意境
- 感悟前人意境者化神后水平一般；自己感悟出独特意境者（如王林的生死意境）化神后极强——**意境 = 角色性格与道的体现**

### 3. "道"的哲学体系

不同修士感悟不同的道：杀戮之道、因果之道、生死之道、轮回之道等。"道"不仅是力量源泉，也是角色性格的体现，把世界观从力量层面提升到哲学层面。世界规则包含轮回、因果等哲学元素。

### 4. 地理与种族

- 地图弧：赵国（凡人国度）→ 朱雀星 → 修魔海 → 联盟星域 → 仙罡大陆
- 种族体系：人族（凝气-问鼎）、仙遗族（一叶-四叶对应）、妖灵（甲数计量）、古神/古妖/古魔三族传承
- 时代背景：修真文明高度发达但资源竞争激烈，弱肉强食是基本法则，"黑暗森林"式尔虞我诈
- 特殊宝物：**天逆珠**（关键金手指，帮助逆天改命）、雨之仙剑等

## 二、主角与剧情主线

主角王林：资质平庸（灵根驳杂）的山村少年，求仙被恒岳宗拒之门外，途中得天逆珠，以记名弟子身份踏上仙途。经历恒岳宗覆灭之仇 → 尸阴宗被困中修炼成古神 → 化名闯荡各界 → 紫系弟子、罗天正品雷仙 → 封界大战中成为界内精神领袖 → 拜师玄罗闭关百年突破踏天境 → 参透轮回真相、斩杀天运子 → 复活爱人李慕婉，携手踏天。

- 人物弧光：从淳朴善良 → 冷酷果断（被残酷修真界逼迫）→ 杀伐果断、智商在线、能动手绝不废话；但内心深处保留对亲情友情爱情的珍视
- 情感核心：**为复活爱人李慕婉而逆天道**——"逆天"的动机不是力量欲望而是情感执念，这是本书区别于纯爽文的关键
- 经典剧情节点：化凡（木匠体验凡人生死）、屠灭藤家全族造人头塔（快意恩仇）、雨夜破庙、以天逆珠取五行之土灵、弥留之际对抗天道使者

## 三、设计亮点

1. **"逆天"主题解构**：主角不是龙傲天，而是在凡人流框架下以凡人之躯对抗整个仙侠世界的规则设定。"逆"字贯穿：逆命运、逆天道、逆等级。修仙动机是情感（复活爱人），落笔始终在人性上
2. **化凡机制**：突破 = 心灵感悟而非单纯资源积累，把"境界突破"从数值事件变成叙事事件——三次化凡各具主题（生死、因果、真假）
3. **反套路 + 高信息密度**：杀伐果断不废话的主角；动画改编把原著 70 章新手村压到 4 集，每集都有兴奋点
4. **压迫感叙事**：筑基期蝼蚁直面元婴期修士威压，通过悬殊差距制造张力
5. **双线成长**：修为线（凝气→踏天）+ 情感线（李慕婉复活执念），情感线驱动修为线

## 四、对本游戏的可借鉴点

- **突破机制设计**：境界突破不仅是材料/修为达标，可加入"感悟"类事件（如化凡体验、道心考验），成为突破成功率的叙事开关——游戏里可做成"突破事件链"
- **意境/道系统**：突破化神/元婴后选择一种"道/意境"（杀戮、因果、生死……），赋予不同战斗加成与文本风格，强化角色个性
- **逆天主题**：游戏世界观可加入"逆天 vs 顺天"阵营选择，影响剧情分支
- **情感驱动目标**：给玩家长线目标（如复活某人/报仇），用叙事目标驱动数值养成
- **黑暗森林式修仙界**：弱肉强食、尔虞我诈的世界基调，适合做 PvP 掠夺、宗门灭门等事件
- **文本素材**：化凡体验（木匠/书生/农夫日常）、雷劫描写、意境感悟文本
