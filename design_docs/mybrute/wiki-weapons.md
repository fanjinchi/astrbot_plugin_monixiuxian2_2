# My Brute 武器系统（Weapons）

> 来源：目标站点 [My Brute Wiki](https://mybrute.fandom.com/wiki/My_Brute_Wiki) 的 [Weapons](https://mybrute.fandom.com/wiki/Weapons) 页面。为保留原始数据，数值、稀有度、标签、英文术语均保留原文。

---

## 1. 概述

- 武器是 My Brute 中特殊的奖励，与 **Specialities（技能）** 和属性加成不同。
- 武器可以被 **throw（投掷）**、**disarm（缴械）**，或被用来直接攻击对手。
- 武器有**稀有度**、**基础伤害区间**、**类型标签**（Fast / Slow / Heavy / Thrown / Melee）以及特殊行为标签（Multi hit / Counter / Disarm / Block）。
- 武器在升级时**随机获得**；玩家无法主动选择或管理武器库。

## 2. 武器类型标签（Weapon Classes）

来源：[Weapons](https://mybrute.fandom.com/wiki/Weapons)

| 标签 | 图标 | 含义 |
|------|------|------|
| **Fast** | Fast.png | 更快的武器，有更高概率获得额外攻击（multi hit），且更难被闪避。 |
| **Slow** | Slow.png | 更慢的武器，获得双连击的概率显著降低，格挡概率也降低。 |
| **Heavy** | Heavy.png | 重型武器，受 **Strong Arm** 技能加成；对 **Lead Skeleton**（类似防御机制）减伤。 |
| **Thrown** | Thrown.png | 投掷武器，只能向对手投掷；不同于单把剑的投掷，通常数量更多。 |
| **Melee** | Melee.png | 近战武器，受 **Master of Arms** 技能加成。 |

### 额外行为标签

来源：[Weapons](https://mybrute.fandom.com/wiki/Weapons)

| 标签 | 含义 |
|------|------|
| **Multi hit** | 有概率在一次攻击中连击多次。 |
| **Counter** | 有概率在对手靠近时进行反击。 |
| **Disarm** | 有概率缴械对手当前武器（即使 Brute 没有 **Impact** 技能）。 |
| **Block** | 持有该武器时有小概率格挡全部 incoming damage。 |

## 5. 武器获取方式

- 武器在 **level up** 时**随机获得**。
- 玩家无法主动选择或丢弃武器（除了战斗中 AI 自动丢弃/投掷）。
- 武器库不可见或被管理，Brute 会随机从已获得的武器中抽取使用。
- 部分武器（如 Stone Hammer、Flail、Whip、Frying Pan、Coffee Cup 等）为稀有或极稀有，获取概率较低。

## 6. 关键设计观察（供重设计参考）

- **标签系统简洁有力**：Fast/Slow/Heavy/Thrown/Melee + Multi hit/Counter/Disarm/Block 用少量标签表达大量武器差异化行为，便于自动战斗结算。
- **伤害区间而非固定值**：每把武器给出一个伤害范围，结合 Strength 和随机系数，保证每次攻击有浮动，提升战斗日志可读性。
- **武器与技能强耦合**：Melee → Master of Arms、Heavy → Strong Arm、Fists → Martial Arts、Thrown → Agility，形成随机 Build 中的“组合惊喜”。
- **武器自带防御/控制能力**：Block、Counter、Disarm 让武器本身成为 Build 的一部分，不只是伤害输出器。
- **稀有度与风格绑定**：Very rare 多为搞笑/趣味武器（Coffee Cup、Keyboard、Trombone、Fan），既有数值也有叙事趣味，适合文字游戏玩梗。
