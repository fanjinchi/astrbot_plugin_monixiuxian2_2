# Delta: level-progression

## MODIFIED Requirements

### Requirement: 突破成功率按大境界配置

突破成功率 SHALL 按目标等级所在大境界查表（默认：练气 100%、筑基 80%、金丹 65%、元婴 55%、化神 50%、炼虚 45%、合体及以后 40% 地板），MUST NOT 再逐級配置成功率。连败保底机制（每败 +5%、19 连败必成）SHALL 保持不变。玩家永久属性 `level_up_rate`（整数百分点）SHALL 作为永久加成源与基础成功率相加（在破境丹上限钳制之前生效）；玩家信息中该项 MUST 仅在值大于 0 时显示。

#### Scenario: 后期成功率不低于地板

- **WHEN** 地仙境界玩家突破
- **THEN** 基础成功率为 40%（不含丹药与连败加成）

#### Scenario: 永久加成参与突破计算

- **WHEN** 玩家 `level_up_rate` 为 5（+5%）且服用破境丹突破
- **THEN** 成功率按「基础 + 5% + 临时加成 + 破境丹加成」计算后再受丹药最大成功率钳制，说明信息包含"永久加成：+5.0%"

#### Scenario: 零加成行为零变化

- **WHEN** 玩家 `level_up_rate` 为 0（当前全量玩家现状）
- **THEN** 突破成功率与引入该字段前完全一致，且玩家信息不显示"突破成功率+X%"项
