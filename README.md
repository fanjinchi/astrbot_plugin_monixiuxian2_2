一款为 AstrBot 设计的、功能丰富的放置类修仙游戏插件。让你在聊天群中体验从凡人到大能的修行之路，工作摸鱼、畅聊吹水的同时亦可得道飞升！

---

## 🌟 特色功能

### 核心玩法
| 系统 | 说明 |
|------|------|
| **境界修炼** | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，九大境界逐步突破 |
| **战斗系统** | 伤害/身法/迅捷/气血四主属性战斗，Muxxu 式伤害公式 + 护甲百分比减伤，支持 PVP（切磋/决斗）和 PVE |
| **宗门系统** | 创建/加入宗门，职位管理，宗门建设与捐献 |
| **世界Boss** | 全服Boss降临，多人合力讨伐，按伤害排名瓜分奖励 |
| **秘境探索** | 挂机式秘境探索，获取丰厚修为与灵石 |
| **历练系统** | 离线挂机获取收益，短途/中途/长途三种时长 |
| **炼丹系统** | 收集材料炼制丹药，提升修为或增加属性 |
| **传承系统** | 修炼累积传承值，PK 争夺传承实例归属，传承排行榜竞技，等阶奖励自动发放 |

### 独有系统
| 系统 | 说明 |
|------|------|
| **🏔️ 洞天福地** | 个人修炼空间，5档洞天可选，持续产出灵石和修为 |
| **🌾 灵田种植** | 开垦灵田种植灵草，5种灵草不同收益周期 |
| **💕 双修系统** | 与他人双修获得定额修为收益（闭关等效时长×境界系数），1小时冷却 |
| **👁️ 天地灵眼** | 抢占灵眼持续获益，PVP资源争夺玩法 |

## 📜 指令大全

### 📖 入门 & 基础
| 指令 | 说明 |
|------|------|
| `我要修仙 [灵修/体修]` | 创建角色，灵修擅法术，体修擅肉身 |
| `我的信息` | 显示境界、修为、战力、装备等完整面板 |
| `签到` | 每日领取灵石(50-500)和修为奖励 |
| `改道号 <名称>` | 修改你的仙道称号 |
| `弃道重修 [确认]` | 删除角色并清空数据，7天内仅可执行一次，需追加“确认” |

## 🎁 道具与丹药手册

| 类别 | 示例 | 作用 | 获取方式 |
|------|------|------|------|
| 破境丹 | 筑基丹、凝婴丹、化神丹 | 直接提升指定境界的突破成功率，部分丹药可将总成功率拉满 | 丹阁刷新、秘境稀有掉落 |
| 修为丹 | 炼气丹、玄灵丹、九转灵丹 | 立即增加修为值（200-10万+），全部存入丹药背包可随时服用 | 丹阁、炼丹系统、历练/秘境结算奖励 |
| 功能丹/灵丹 | 修炼加速丹、力量丹、灵智丹、回生丹 | 包含临时修炼倍率、永久属性增减、复活、定魂护盾等特殊效果 | 丹阁稀有刷新、Boss与高阶秘境掉落 |
| 百宝丹药（即时消耗） | 一品气血丹、三品凝神增益丹 | 购买后立即恢复气血/灵气、增减属性或短暂提升突破成功率 | 百宝阁限量出售（无法存入背包） |
| 材料 | 灵草、玄铁、星辰石、天材地宝 | 炼丹配方、悬赏任务、装备升级所需的基础资源 | 历练、秘境、悬赏、世界Boss掉落，灵田收获可持续产出灵草 |
| 法器/功法 | 青锋剑、玄铁甲、焚天诀、他化自在大法 | 装备/心法提供伤害、身法、迅捷、气血、护甲与修炼倍率等长期加成 | 器阁 / 百宝阁刷新，高级 Boss 亦可掉落稀有法器 |

💡 使用 `物品信息 <名称>` 可随时查询任意上架物品或丹药的详细效果与推荐获取途径。

## ⚙️ 配置说明

插件首次运行后，将在 `data/plugins/astrbot_plugin_monixiuxian2_2/config/` 目录下自动生成默认配置文件：

| 配置文件 | 作用 |
|---------|------|
| `sect_config.json` | 宗门创建消耗、职位权限、任务奖励 |
| `boss_config.json` | Boss 属性成长曲线、生成间隔 |
| `rift_config.json` | 秘境名称、等级要求、探索时长、奖励池 |
| `alchemy_config.json` | 丹药配方、材料消耗、成功率计算 |

**注意**：修改配置后需重启 AstrBot 生效。

1. 确保已安装 AstrBot
2. 将插件文件夹放入 `data/plugins/` 目录
3. 安装依赖：`pip install -r requirements.txt`

### v3.11.0 - 传承系统改版：PK 夺取制与修炼累积

**💥 破坏性变更**

- **传承 PK 重做**：挑战胜利不再随机获得 1~5 传承值，改为**夺走对方最新一条可夺传承**（宗门传承除外）；败者保留现有惩罚（扣 1% 修为）并新增 **5 天冷却**（同对手）；被夺方享有 **3 日保护期**（期间任何挑战被拒）
- **传承值改为修炼累积**：出关时按修炼时长累积传承值（每 15 分钟 1 点），仅**激活中的传承**累积；新增「激活传承」指令（同时间仅一条激活）
- **一人可持多条传承实例**：`impart_info` 表迁移为 `legacy_instances`（id/owner/type/value/claimed_tiers/sect_id/is_active），奖励按实例独立发放；传承值不参与 PK 计算，也不进战力公式
- **传承获取途径**：宗门宝库（新增宗门传承，不可被 PK、离宗/被踢自动回收）、历练/秘境机缘（触发守护 NPC 挑战，胜利后获得该类型传承，概率可配置）
- **配置重构**：`impart_config.json` 按类型分组（common/sect/adventure/rift），奖励掉落修复（传承心法/功法 id 经 content-design 管道补齐）
- **新增 GM 子命令**：「给予传承」「清除传承」「清除传承状态」（测试预置/清理，仅 GM_ADMINS）

---

### v3.10.0 - 宗门指令统一入口与宗门专属内容独立

**💥 破坏性变更**
- 宗门功能全部收敛为「宗门」单顶层指令 + 子命令（如「宗门 信息」「宗门 捐献」「宗门 任务」），原 18 个宗门顶层指令（创建宗门/加入宗门/我的宗门/宗门捐献/宗门任务/宗门丹房/宗门建设/镇派功法/宗门晋升/宗门宝库/师承任务/宗门排行/贡献排行 等）已全部删除，发送「宗门」可查看完整子命令导航

### v2.9.5 - 悬赏系统安全加固

**🔒 安全修复**
| 问题 | 严重程度 | 修复 |
|------|---------|------|
| 奖励发放与任务完成非原子操作 | 🔴严重 | 使用 `BEGIN IMMEDIATE` 事务保护，防止并发重复领奖 |
| 放弃任务无冷却机制 | 🟠中等 | 放弃悬赏后30分钟内无法接取新任务 |
| 并发领取风险 | 🟠中等 | 事务内先标记完成再发放奖励 |

**🛡️ 事务安全改进**
- `complete_bounty` 现在使用 SQLite 事务保护
- 奖励发放顺序：先标记任务完成 → 再发放灵石/修为 → 最后发放物品
- 物品奖励在事务外处理，失败不影响主奖励

### v2.5.0 - 储物戒系统重构

**🎯 核心改造：储物戒成为游戏物品流转的中央枢纽**

**📦 系统联动（8个系统接入）**
| 系统 | 入库场景 | 出库场景 |
|------|---------|---------|
| 商店系统 | 购买物品→自动存入 | - |
| 装备系统 | 卸下装备→存入 | 装备→从储物戒取出 |
| 炼丹系统 | - | 炼丹→消耗储物戒材料 |
| 历练系统 | 完成历练→物品掉落 | - |
| 秘境系统 | 探索完成→物品掉落 | - |
| Boss系统 | 击杀奖励→物品掉落 | - |
| 悬赏系统 | 完成悬赏→物品奖励 | - |
| 灵田系统 | 收获灵草→存入储物戒 | - |

**🆕 新增功能**
- 物品分类视图：按材料/装备/功法/其他分组显示
- 物品搜索：`搜索物品 关键词` 模糊搜索
- 批量取出：`取出所有 分类` 批量操作
- 储物戒升级消耗：需支付灵石购买

**🔧 修复问题**
- 炼丹现在正确消耗储物戒中的灵草材料
- 装备物品必须先存在于储物戒中
- 赠予请求持久化到数据库（24小时有效期）
